# 过程文档目录

> `workdocs/` 是过程层根目录，用来承载需求、方案、任务拆解、评审和验收材料。

## 目录职责

| 目录 | 作用 |
|---|---|
| `workdocs/需求/` | 当前需求基线、范围、约束、验收门槛 |
| `workdocs/方案/` | 设计说明、实施思路、规划产物 |
| `workdocs/任务拆解/` | 任务拆分、工作包、并行执行材料 |

## 过渡说明

当前仓库里仍有一批历史过程文档保留在旧路径：

- `docs/plans/`
- `docs/内部参考/迭代需求/`
- `docs/内部参考/任务拆解/`

这些旧路径暂时继续存在，方便追溯；新的过程层根目录以 `workdocs/` 为准。
