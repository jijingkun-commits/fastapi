## 4. Defect List（问题清单）

### D-01 数据库连接阻断（P0）

- 证据：`psycopg.OperationalError ... localhost:5432 ... Connection refused`
- 影响：
  - `app/tests/test_todo_db_integration.py` 相关用例均 error。
  - `tests/api/test_data_admin_api.py::TestQueryLogAPI` 相关用例 error。
  - 启动时 checkpointer 初始化失败，影响 E2E 稳定性。
- 建议：先恢复本地 PostgreSQL（`chat_db`）可连通，再复测。

### D-02 DataAccessControl 白名单加载失败（P0）

- 证据：`data_access_control.py:165` 加载白名单失败后 fallback，`t_orders` 被拒绝。
- 影响：
  - `app/tests/test_data_agent.py::test_check_table_access_whitelist`
  - `app/tests/test_data_agent.py::test_validate_sql_valid`
- 建议：在 DB 可用后复核系统配置 `data_access.table_whitelist` 与默认值策略。

### D-03 模型配置密钥缺失（P0）

- 证据：`ValueError: 配置错误：无法获取 model=... 的 API Key`（`app/ai/llm_util.py:431`）
- 影响：`app/tests/test_model_switch.py` 多 case 失败。
- 建议：补齐测试环境模型密钥或在单测中统一 mock `get_llm` 依赖。

### D-04 待办集成 patch 目标漂移（P1）

- 证据：`AttributeError: module 'app.ai.agents' has no attribute 'todo_graph'`
- 影响：`app/tests/test_todo_graph_integration.py` 2 个 case 失败。
- 建议：将 patch 目标迁移到当前实际模块路径（`app.ai.workflow.todo_graph`）。

### D-05 异步测试运行环境不完整（P1）

- 证据：`async def functions are not natively supported`
- 影响：`app/tests/test_todo_multiround.py` 3 个 case 失败。
- 建议：统一 pytest 异步插件与 marker 配置（如 `pytest-asyncio`）。

### D-06 E2E setup 稳定性问题（P1）

- 证据：`auth.setup` 出现超时 / `page.goto('/auth')` 中断。
- 影响：全量 Playwright 回归不稳定，后续用例大量未执行。
- 建议：先稳定后端依赖与登录前置，再执行全量 E2E。
