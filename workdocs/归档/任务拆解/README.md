# 历史 Task Split 归档

> 这里只放**已经结束**的 task bundle。
> 仍在驱动脚本执行的 bundle，继续留在 `workdocs/任务拆解/`。

## 进入这里之前必须满足

1. 不再存在活跃 `contracts/_active_task.json` 写入口
2. `consumption_report.json`、`gate_contract_report.json` 等关键报告已收口
3. 需求 / 设计 / 实施计划 / 审查 / 验收等正文已经在 `workdocs/归档/*` 有稳定落点
4. 真实运行态已经完全进入 `.artifacts/states/task_splits/`

## 放这里之后的定位

- 只回答“当时这件事是怎么拆卡、怎么执行的”
- 不再作为当前执行入口
- 不再承载新的状态写入

## 典型内容

- `parallel_plan.md`
- `workstreams/*.md`
- `contracts/*.json`
- `reports/*.json`
- 历史 task bundle 的说明页
