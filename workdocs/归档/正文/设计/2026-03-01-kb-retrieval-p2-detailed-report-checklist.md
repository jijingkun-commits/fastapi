## 0. 报告元信息完整性

- [ ] 报告标题明确（包含阶段名与日期）。
- [ ] 报告人/评审人/负责人完整。
- [ ] 报告覆盖周期明确（开始时间、结束时间、样本窗口）。
- [ ] 关联代码分支、提交范围、发布批次已记录。
- [ ] 关联监控面板/日志查询链接已记录。

---

## 1. 目标与范围对齐

- [ ] 报告明确本次阶段目标（S0/S1/S2/S3/S4/S5）。
- [ ] 报告明确非目标（本阶段不做什么）。
- [ ] 报告范围与设计文档一致，无越界新增需求。
- [ ] 变更项与原计划差异（新增/删除/延期）已说明原因。

---

## 2. 证据采集完整性（必须有可追溯证据）

- [ ] 每项结论都有证据（日志、SQL、截图、测试输出）支持。
- [ ] 证据包含时间戳、环境（dev/staging/prod）、样本数量。
- [ ] 证据可复现：给出命令/脚本/查询条件。
- [ ] 关键日志字段齐全（`query_hash`、`page_size`、`top_k`、`selected_doc_ids`、`context_chars`、`truncation_flag`）。
- [ ] 对比数据包含“变更前 vs 变更后”。

---

## 3. 指标达成与解释

### 3.1 统一放行指标

- [ ] 人工相关性@5 >= 80%。
- [ ] 错误引用率 <= 5%。
- [ ] 两项指标同时达标（未出现“单项达标强行推进”）。

### 3.2 指标解释质量

- [ ] 指标计算口径已写清（样本数、分母定义、统计窗口）。
- [ ] 结果波动解释充分（区分真实提升与抽样偏差）。
- [ ] 异常样本清单已附录（不少于 Top 问题样本）。
- [ ] 未达标项有纠偏计划与下一次评估时间。

---

## 4. 分阶段闸门清单（S0-S5）

### S0 基线建立

- [ ] 30-50 条业务样本集已固化并归档。
- [ ] 样本标注通过双人复核与冲突仲裁。
- [ ] 基线报告已输出且可重复运行。
- [ ] 重复跑两次指标波动 < 5%。

### S1 契约修正（`page_size/top_k` 解耦）

- [ ] 检索请求显式传入 `page_size`。
- [ ] `top_k` 仅用于向量候选深度语义。
- [ ] 参数配置可动态调整并记录生效值。
- [ ] 抽检 20 条 Top8 结果，噪声明显下降。

### S2 候选清洗

- [ ] 同文档候选上限生效（例如每文档 <= 2）。
- [ ] 文档级去重生效（相似段落不重复刷屏）。
- [ ] 证据压缩策略生效（卡片化摘要而非全量堆叠）。
- [ ] 答案到证据可一一追溯。

### S3 查询改写

- [ ] 原问主路保留并有保底权重。
- [ ] 扩展问生成规则已记录（术语/同义词/场景词）。
- [ ] 多路融合排序规则已记录。
- [ ] 模糊问题集前后对比评审已完成（>= 20 条）。

### S4 领域路由

- [ ] 领域词典已版本化。
- [ ] metadata 过滤策略已启用并记录。
- [ ] 路由失败有回退策略（回退全库检索）。
- [ ] 跨域误召回样本审查已完成。

### S5 灰度放量

- [ ] 已按 10% -> 30% -> 100% 执行或给出偏离说明。
- [ ] 每日指标日报已归档。
- [ ] 每日 badcase 会审记录完整。
- [ ] 连续 3 天达标后才全量。

---

## 5. 测试与质量门禁

### 5.1 自动化测试

- [ ] 单元测试覆盖：参数构造、去重、重排、改写融合。
- [ ] 集成测试覆盖：RAGFlow 请求契约与降级路径。
- [ ] 离线评测脚本可一键执行并输出结构化结果。
- [ ] 灰度巡检任务稳定运行（延迟、空结果率、错误率、引用异常率）。

### 5.2 人工评审

- [ ] 业务评审结论与技术评审结论均已签字。
- [ ] QA 回归结论明确（通过/阻塞/风险放行）。
- [ ] 争议样本有仲裁结论。

---

## 6. 风险、回滚与应急预案

- [ ] 已识别本阶段 Top 风险（至少 3 条）。
- [ ] 每条风险都有检测信号与阈值。
- [ ] 每条风险都有回滚动作（开关、配置、版本回退）。
- [ ] 回滚路径已演练（至少在 staging 验证一次）。
- [ ] 负责人与响应 SLA 已明确。

---

## 7. 成本与收益复盘

- [ ] 开发/测试/评审耗时已统计。
- [ ] 线上收益已量化（相关性提升、错引下降、人工工单下降）。
- [ ] 是否达到阶段 ROI 预期有结论。
- [ ] 下一阶段投入建议已给出（继续推进/暂停/调整）。

---

## 8. 发布与归档清单

- [ ] 报告已存档到 `workdocs/归档/正文/设计/` 且命名规范。
- [ ] 关联文档索引（`docs/SUMMARY.md`）已更新。
- [ ] 关联任务状态（进行中/完成/阻塞）已同步。
- [ ] 结论同步到团队沟通渠道（日报/周报/评审会）。

## 10. 最终放行总检查（Go/No-Go）

- [ ] 目标达成且证据充分。
- [ ] 指标达标且口径一致。
- [ ] 风险可控且回滚可用。
- [ ] 评审通过且责任人确认。

> 放行规则：以上四项任一不满足，结论必须为 **No-Go**。
