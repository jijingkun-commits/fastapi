# 双仓库同步配置指南

本项目配置为 **Gitee (主仓库)** + **GitHub (CI 仓库)** 双仓库模式。

## 1. 在 GitHub 创建仓库

1. 打开 https://github.com/new
2. Repository name: `fastapi` (建议与 Gitee 一致)
3. 选择 **Private** 或 **Public**
4. **不要勾选** "Add a README file"
5. 点击 **Create repository**

## 2. 添加 GitHub Remote

仓库创建后，运行以下命令（将 `你的GitHub用户名` 替换为实际值）：

```bash
git remote add github https://github.com/你的GitHub用户名/fastapi.git
```

验证配置：
```bash
git remote -v
# 应显示:
# github  https://github.com/xxx/fastapi.git (fetch)
# github  https://github.com/xxx/fastapi.git (push)
# origin  https://gitee.com/jijingkun/fastapi.git (fetch)
# origin  https://gitee.com/jijingkun/fastapi.git (push)
```

## 3. 配置 GitHub Secrets

在 GitHub 仓库页面，进入 **Settings > Secrets and variables > Actions**，添加以下 Secrets：

| Secret 名称 | 说明 | 必填 |
| :--- | :--- | :--- |
| `QWEN_API_KEY` | 通义千问 API Key | ✅ |
| `JWT_SECRET` | JWT 签名密钥 | ❌ (有默认值) |

## 4. 日常使用

### 方式一：使用同步脚本 (推荐)

```bash
# 同步推送到两个仓库
./scripts/sync-repos.sh

# 指定分支
./scripts/sync-repos.sh develop
```

### 方式二：手动推送

```bash
git push origin main    # 推到 Gitee
git push github main    # 推到 GitHub (触发 CI)
```

## 5. 查看 CI 结果

1. 打开 GitHub 仓库页面
2. 点击 **Actions** 标签
3. 查看 `Playwright E2E Tests` 工作流状态

## 常见问题

### Q: 推送到 GitHub 时提示认证失败？
A: 需要配置 GitHub Personal Access Token。运行：
```bash
# 使用 HTTPS + Token 方式
git remote set-url github https://TOKEN@github.com/用户名/fastapi.git
```
或使用 SSH 方式：
```bash
git remote set-url github git@github.com:用户名/fastapi.git
```

### Q: 两个仓库代码不同步怎么办？
A: 以 Gitee 为准，强制推送到 GitHub：
```bash
git push github main --force
```
