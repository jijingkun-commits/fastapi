### 发现的问题

#### 1. Supervisor → todo_expert 子图调用问题

**现象**：每次调用都显示 "supervisor 在处理任务时遇到内部错误: Command(...)"

**原因**：`multi_agent_graph.py` 中的 `handoff_tool` 返回 `Command` 对象，但 `streaming_wrapper` 将其当作异常处理（第 620-628 行）。

**影响**：
- ✅ 意图分析正确（关键词检测通过）
- ✅ 路由决策正确（正确识别为待办任务）
- ❌ 待办创建失败（todo_expert 子图未实际执行）
- ❌ 数据库无待办记录

**建议修复**：检查 `streaming_wrapper` 中对 `Command` 对象的处理逻辑。

#### 2. 待办 API 路径问题

**现象**：查询待办返回 404

**可能原因**：API 路径不正确或用户权限问题
