# 知识库检索指南

> 本参考文档供 AI Agent 按需加载

## 使用场景

| 场景 | 说明 | 示例查询 |
|------|------|----------|
| 公司政策 | 规章制度、流程 | "公司差旅报销规定" |
| 产品文档 | 产品说明、操作手册 | "XX产品使用说明" |
| 技术资料 | 技术文档、API 说明 | "API 接口文档" |
| 培训材料 | 培训课件、教程 | "新员工入职培训" |

## 查询规则

### ✅ 正确做法

1. **直接使用用户原话**
   ```
   用户: "公司请假规定是什么"
   query: "公司请假规定是什么"
   ```

2. **保留关键词**
   ```
   用户: "XXX产品的安装步骤"
   query: "XXX产品的安装步骤"
   ```

### ❌ 错误做法

1. **添加额外关键词**
   ```
   用户: "请假规定"
   query: "请假规定 假期 休假 考勤"  ← 错误！
   ```

2. **改写用户表述**
   ```
   用户: "怎么报销差旅费"
   query: "差旅费用报销流程及标准"  ← 错误！
   ```

## 结果处理

1. **按相关度排序**：优先使用得分最高的结果
2. **保留图片链接**：如果结果包含图片，在回复中展示
3. **消化整理**：不要原样输出检索结果
4. **引用来源**：必要时注明文档来源
