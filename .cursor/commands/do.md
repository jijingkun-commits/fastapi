# Do - 执行实施

按照计划执行代码修改，并完成测试和审查。

## 何时使用

- 已有明确的实施计划
- 准备开始编码

## 执行流程

1. **读取计划**：从 `workdocs/设计/` 读取计划文档
2. **逐任务执行**：
   - 修改代码
   - 运行验收命令
   - 确认通过后继续下一个
3. **自动审查**：
   - 检查代码质量
   - 运行相关测试
   - 检查文档同步
4. **提交代码**：生成 commit message 并提交

## 智能判断

- 如果任务 > 5 个，自动拆分为多个 commit
- 如果涉及多个模块，建议使用 worktree
- 如果测试失败，自动回滚并报告

## 输出

- 代码修改（已提交）
- 测试结果
- 完成报告（哪些完成、哪些未完成、遇到的问题）

## 下一步

完成后可以：
- 创建 PR（如果需要）
- 继续下一个任务
- 或结束
