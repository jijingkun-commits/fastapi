# Lint 检查与修复 (Lint & Fix)

分析当前文件或目录的代码规范问题，并自动修复。

> **中文主导**: 无论是思考过程（CoT）还是最终输出，**永远使用中文**。

## 何时使用

| 场景 | 推荐命令 |
|------|----------|
| 检查代码规范并自动修复 | `/lint` ✅ |
| 深度代码重构 | `/refactor` |
| 完整代码审查 | `/review` |

---

## 执行步骤

### 1. 识别问题

**Python (后端)**:
```bash
# 运行 ruff 检查
ruff check app/ --fix
# 运行类型检查
mypy app/ --ignore-missing-imports
```

**TypeScript (前端)**:
```bash
cd web
npm run lint -- --fix
npx tsc --noEmit
```

### 2. 检查清单

- [ ] 代码格式和风格一致性
- [ ] 未使用的导入和变量
- [ ] 类型安全问题
- [ ] 最佳实践违规
- [ ] 潜在的运行时错误

### 3. 应用修复

- 自动修复可修复的问题
- 对于需要手动处理的问题，提供具体修复建议
- 解释做了哪些更改

## 文档同步

> **强制要求**: 如果 lint 修复导致代码行为变更，必须同步更新相关文档。
