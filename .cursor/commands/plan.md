# Plan - 实施规划

将设计方案转化为具体的实施计划。

## 何时使用

- 已有明确的设计方案
- 需要拆解为具体任务
- 需要评估工作量

## 执行流程

1. **读取设计**：从 `docs/plans/` 读取设计文档
2. **拆解任务**：拆解为具体的实施步骤
3. **评估风险**：识别技术风险和依赖
4. **产出计划**：生成实施计划文档

## 输出

在 `docs/plans/YYYY-MM-DD-<topic>-plan.md` 产出计划文档，包含：
- 任务列表（按优先级排序）
- 每个任务的：
  - 涉及文件
  - 修改内容
  - 验收命令
- 风险与依赖

## 下一步

计划确认后，使用 `/do` 执行实施。
