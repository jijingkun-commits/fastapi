# 数据库迁移 (Database Migration)

帮助创建和管理数据库迁移，确保数据安全和可回滚。

> **中文主导**: 无论是思考过程（CoT）还是最终输出，**永远使用中文**。

## 何时使用

| 场景 | 推荐命令 |
|------|----------|
| 需要修改数据库表结构 | `/migration` ✅ |
| 编写代码实现功能 | `/imp` |
| 完整功能开发 | `/feature` |

---

## 执行步骤

### 1. 迁移分析

- 审查需要的数据库结构变更
- 识别数据转换需求
- 检查潜在的数据丢失或损坏风险
- 分析对性能的影响

### 2. 创建迁移脚本

**脚本位置**: `install/scripts/init_postgres.sql/`

**命名规范**: `NNN_描述.sql`（如 `018_add_user_profile.sql`）

**脚本结构**:
```sql
-- 迁移说明：描述此迁移的目的
-- 创建日期：YYYY-MM-DD
-- 作者：xxx

-- UP: 正向迁移
BEGIN;

-- 你的 DDL 语句
ALTER TABLE t_xxx ADD COLUMN xxx;

COMMIT;

-- DOWN: 回滚脚本（注释保留，需要时手动执行）
-- BEGIN;
-- ALTER TABLE t_xxx DROP COLUMN xxx;
-- COMMIT;
```

### 3. 验证迁移

- [ ] 在开发环境执行迁移
- [ ] 验证数据完整性
- [ ] 测试回滚脚本
- [ ] 检查性能影响

### 4. 文档同步

> **强制要求**: 数据库变更必须同步更新文档。

**Checklist**:
- [ ] 表结构变更 -> 更新 `docs/开发文档/架构设计/数据库设计.md`
- [ ] 新增索引 -> 记录在数据库设计文档中
- [ ] 数据迁移 -> 记录迁移步骤和回滚方案
