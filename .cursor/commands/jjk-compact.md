# JJK Compact

`/jjk-compact` 用于把当前上下文压成一段可直接复制到另一个 Codex 窗口的精简交接提示词。

## 何时使用

1. 需要把当前任务交给另一个窗口继续做；
2. 需要快速生成 handoff prompt；
3. 只想要最终提示词，不想看解释。

## 输入

提供任一即可：

1. 一段背景和任务描述；
2. 当前会话里的上下文；
3. 文件、文档或报告路径。

## 输出顺序

1. 背景
2. 要做的事
3. 已知约束
4. 成功标准

## 压缩规则

1. 只保留另一个窗口开工必需的信息；
2. 优先保留：目标、范围、关键文件、硬约束、验收口径；
3. 缺少细节时，用最小可信说法，不擅自发明事实；
4. 默认只输出最终提示词，不加前后解释；
5. 除非用户明确要求，尽量控制在 `8-12` 行。

## 禁止项

1. 不输出分析过程；
2. 不把问题重新抛回用户；
3. 不写“下面是提示词”之类的包裹语；
4. 不展开成长文档或长计划。

*使用 `/jjk-compact` 触发。目标是“快速产出可复制交接 prompt”，不是重新跑一遍 `/jjk-clarify`、`/jjk-design` 或 `/jjk-plan`。*
