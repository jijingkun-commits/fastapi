## 功能模块详解

### 1. 数据访问控制模块 (`/access-admin`)

管理 SQL 查询的数据访问权限，支持白名单/黑名单机制。

| 功能 | API 端点 | 说明 |
|------|----------|------|
| 获取完整配置 | `GET /access-admin/config` | 返回白名单、黑名单、Schema白名单的完整配置 |
| 获取表白名单 | `GET /access-admin/whitelist` | 获取允许查询的表列表及来源（database/default） |
| 更新表白名单 | `PUT /access-admin/whitelist` | 批量更新白名单表列表 |
| 添加到白名单 | `POST /access-admin/whitelist/add?table_name=xxx` | 单个添加表到白名单 |
| 从白名单移除 | `DELETE /access-admin/whitelist/{table_name}` | 从白名单移除指定表 |
| 获取表黑名单 | `GET /access-admin/blacklist` | 获取禁止查询的表列表 |
| 更新表黑名单 | `PUT /access-admin/blacklist` | 批量更新黑名单表列表 |
| 获取 Schema 白名单 | `GET /access-admin/schema-whitelist` | 获取允许访问的 Schema 列表 |
| 更新 Schema 白名单 | `PUT /access-admin/schema-whitelist` | 更新 Schema 白名单 |
| SQL 权限测试 | `POST /access-admin/test-sql` | 验证 SQL 语句的表访问权限（不执行） |
| 获取可用表 | `GET /access-admin/available-tables` | 列出业务数据库中所有可用表（用于 UI 选择） |

### 2. LLM 配置管理模块 (`/llm-admin`)

管理 LLM 提供商和模型配置。

**提供商管理：**

| 功能 | API 端点 | 说明 |
|------|----------|------|
| 提供商列表 | `GET /llm-admin/providers` | 获取所有提供商（API Key 自动脱敏） |
| 提供商详情 | `GET /llm-admin/providers/{id}` | 获取单个提供商详情 |
| 创建提供商 | `POST /llm-admin/providers` | 创建新提供商（code/name/base_url/api_key） |
| 更新提供商 | `PUT /llm-admin/providers/{id}` | 更新提供商信息 |
| 删除提供商 | `DELETE /llm-admin/providers/{id}` | 删除提供商（级联删除关联模型） |
| 更新 API Key | `PUT /llm-admin/providers/{id}/api-key` | 单独更新提供商的 API Key |

**模型管理：**

| 功能 | API 端点 | 说明 |
|------|----------|------|
| 模型列表 | `GET /llm-admin/models` | 获取模型列表（支持按提供商/类型/状态筛选） |
| 模型详情 | `GET /llm-admin/models/{id}` | 获取单个模型详情 |
| 创建模型 | `POST /llm-admin/models` | 创建新模型（含能力配置） |
| 更新模型 | `PUT /llm-admin/models/{id}` | 更新模型配置 |
| 删除模型 | `DELETE /llm-admin/models/{id}` | 删除模型 |
| 设为默认 | `PUT /llm-admin/models/{id}/set-default` | 设置为同类型的默认模型 |
| 切换启用 | `PUT /llm-admin/models/{id}/toggle-active` | 切换模型启用/禁用状态 |
| 模型类型 | `GET /llm-admin/model-types` | 获取所有模型类型及其默认模型 |

**模型属性说明：**

| 属性 | 类型 | 说明 |
|------|------|------|
| `model_type` | string | 模型类型：chat/embedding/reasoning/vision |
| `supports_thinking` | bool | 是否支持思考模式 |
| `supports_tool_call` | bool | 是否支持工具调用 |
| `supports_streaming` | bool | 是否支持流式输出 |
| `max_output_tokens` | int | 最大输出 token 数 |
| `context_window` | int | 上下文窗口大小 |
| `default_temperature` | float | 默认温度参数 |
| `thinking_budget` | int | 思考模式 token 预算 |

### 3. 技能管理模块 (`/skill-admin`)

管理 AI Agent 技能库及向量索引。

| 功能 | API 端点 | 说明 |
|------|----------|------|
| 技能列表 | `GET /skill-admin/skills` | 分页获取技能列表（支持搜索、筛选） |
| 技能详情 | `GET /skill-admin/skills/{skill_id}` | 获取技能完整内容 |
| 删除技能 | `DELETE /skill-admin/skills/{skill_id}` | 删除指定技能 |
| 向量状态 | `GET /skill-admin/vector-status` | 获取向量索引状态（总数/维度/匹配情况） |
| 批量重建向量 | `POST /skill-admin/regenerate-embeddings` | 重新生成全部或指定技能的向量 |
| 单个重建向量 | `POST /skill-admin/skills/{skill_id}/regenerate` | 重新生成单个技能的向量 |
| 技能搜索 | `GET /skill-admin/search?query=xxx` | 向量相似度搜索（支持 top_k 和阈值） |

**向量状态响应字段：**

| 字段 | 说明 |
|------|------|
| `total_skills` | 技能总数 |
| `with_embedding` | 有向量的技能数 |
| `without_embedding` | 无向量的技能数 |
| `embedding_dim` | 现有向量维度 |
| `current_model_dim` | 当前 embedding 模型维度 |
| `dimension_mismatch` | 维度是否不匹配（需重建） |

### 4. 系统配置管理模块 (`/system-admin`)

管理系统级配置项。

| 功能 | API 端点 | 说明 |
|------|----------|------|
| 配置列表 | `GET /system-admin/configs` | 获取配置列表（支持按分类筛选） |
| 配置详情 | `GET /system-admin/configs/{key}` | 获取单个配置详情 |
| 更新配置 | `PUT /system-admin/configs/{key}` | 更新配置值（只读配置无法修改） |
| 创建配置 | `POST /system-admin/configs` | 创建新配置项 |
| 删除配置 | `DELETE /system-admin/configs/{key}` | 删除配置项（只读配置无法删除） |
| 分类列表 | `GET /system-admin/categories` | 获取所有配置分类及数量 |
| 刷新缓存 | `POST /system-admin/refresh-cache` | 手动刷新配置缓存 |

**配置属性说明：**

| 属性 | 类型 | 说明 |
|------|------|------|
| `config_key` | string | 配置键名 |
| `config_value` | string | 配置值（敏感值自动脱敏） |
| `value_type` | string | 值类型：string/int/bool/json |
| `category` | string | 分类：ai/mcp/ragflow 等 |
| `is_secret` | bool | 是否敏感配置 |
| `is_readonly` | bool | 是否只读 |

## 发现的问题

### Bug #1: 向量状态 API 数组判断错误 (已修复)

**文件**: `app/api/v1/endpoints/skill_admin_api.py:149`

**问题**: `if sample.embedding` 对 numpy 数组会报 ValueError

**修复**:
```python
# 修复前
embedding_dim = len(sample.embedding) if sample and sample.embedding else None

# 修复后  
embedding_dim = len(sample.embedding) if sample is not None and sample.embedding is not None else None
```
