# 项目上下文 (AI Quick Reference)

## 一句话

多智能体 AI 助手系统（LangGraph + FastAPI + Next.js）

## 代码入口

| 功能 | 文件 |
|-----|------|
| 后端启动 | `app/main.py` |
| AI 核心图 | `app/ai/workflow/multi_agent_graph.py` |
| 待办图 | `app/ai/workflow/todo_graph.py` |
| 前端入口 | `web/src/app/page.tsx` |
| 配置 | `.env.dev`, `app/core/config.py` |

## 规则位置

| 类型 | 路径 | 什么时候看 |
|-----|------|------|
| 根入口 | `AGENTS.md` | 仓内任务默认先看这里 |
| Codex 运行技能 | `.agents/skills/*/SKILL.md` | 命中对应 workflow / skill 时优先看 |
| Cursor 规则 | `.cursor/rules/*.mdc` | 命中对应主题时按需看 |
| 命令真理源 | `.cursor/commands/*.md` | 只在维护命令定义 / 查镜像漂移时看 |
| 核心原则 | `.cursor/rules/core.mdc` | 需要确认全局技术口径时看 |
