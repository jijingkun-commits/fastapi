## 项目简介

**一句话描述**: 基于 LangGraph 的多智能体 AI 助手系统，支持聊天、待办管理和数据分析。

## 技术栈

| 分类 | 技术 |
|------|------|
| 后端 | FastAPI + LangGraph + SQLAlchemy |
| 前端 | Next.js 15 + React 19 + TailwindCSS |
| 数据库 | PostgreSQL + pgvector |
| 对象存储 | MinIO |
| AI 框架 | LangChain + LangGraph |

## 核心模块

- **多智能体系统**: Supervisor + 专家 Agent (数据专家、待办专家)
- **SSE 流式通信**: 实时 Token 流 + Tool 调用事件
- **待办助手**: AI 驱动的任务管理
- **知识库问答**: RAGFlow 集成
- **Skills RAG**: 动态技能检索增强
