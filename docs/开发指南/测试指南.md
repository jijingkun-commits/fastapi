# 测试指南

项目测试框架和运行方法。

## 测试框架

- **后端**: pytest
- **前端 E2E**: Playwright

---

## 运行后端测试

```bash
# 安装测试依赖
pip install -e ".[dev]"

# 运行所有测试
pytest

# 运行特定测试
pytest app/tests/test_todo.py

# 显示详细输出
pytest -v
```

### 测试目录

```
app/tests/
├── test_todo.py          # 待办测试
├── test_chat.py          # 聊天测试
└── conftest.py           # 测试配置
```

---

## 运行前端测试

```bash
cd web

# E2E 测试
npm run test:e2e

# 有界面模式
npm run test:e2e:ui
```

### E2E 测试目录

```
web/e2e/
├── todo.spec.ts          # 待办功能测试
├── chat.spec.ts          # 聊天功能测试
└── auth.spec.ts          # 认证测试
```

---

## 测试数据库

测试使用独立数据库：

```bash
# 设置测试数据库
export DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5432/test_db
```

---

## CI 集成

GitHub Actions 自动运行测试：

```yaml
# .github/workflows/ci.yml
- name: Run Tests
  run: pytest
```
