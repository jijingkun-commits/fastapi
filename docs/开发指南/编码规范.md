# 编码规范

项目编码规范，确保代码风格一致性。

## 通用规则

- **所有注释使用中文**
- 思考和输出使用中文

---

## Python 规范

### 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 文件名 | snake_case | `chat_service.py` |
| 类名 | PascalCase | `ChatService` |
| 函数/变量 | snake_case | `get_user_by_id` |
| 常量 | UPPER_SNAKE_CASE | `MAX_RETRY_COUNT` |

### 类型提示

必须使用 Type Hints：

```python
from typing import Optional, List

def get_todos(user_id: int, status: Optional[str] = None) -> List[Todo]:
    ...
```

### 模块文档

每个模块顶部必须包含 docstring：

```python
"""待办服务模块（中文说明）。

提供待办事项的业务逻辑处理。
"""
```

### ORM 模型

使用 SQLAlchemy 2.0 语法：

```python
class Todo(Base):
    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(500), nullable=False)
```

---

## TypeScript 规范

### 类型定义

严格使用 TypeScript，避免 `any`：

```typescript
interface Todo {
  id: number;
  title: string;
  status: 'todo' | 'in_progress' | 'done';
}
```

### 组件命名

- 组件文件：PascalCase（`ChatInput.tsx`）
- Hook 文件：camelCase（`useSSEStream.ts`）

---

## 数据库规范

- 表名以 `t_` 开头
- 字段使用 snake_case
- 主键统一为 `id`
