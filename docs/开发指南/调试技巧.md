# 调试技巧

开发过程中的调试方法和常见问题解决。

## 日志查看

### 后端日志

```bash
# 实时查看日志
tail -f logs/assistant.log

# 按级别过滤
grep "ERROR" logs/assistant.log
```

### 日志级别

开发环境默认 DEBUG，可在 `.env.dev` 修改：

```bash
LOG_LEVEL=DEBUG
```

---

## API 调试

### 使用 Swagger UI

访问 `http://localhost:8000/docs`

### 使用 curl

```bash
# 登录
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"secret"}'

# 获取待办
curl http://localhost:8000/api/v1/todo \
  -H "Authorization: Bearer <token>"
```

## LangGraph 调试

### 启用详细日志

```python
import logging
logging.getLogger("langgraph").setLevel(logging.DEBUG)
```

### 查看图结构

```python
from app.ai.workflow.multi_agent_graph import create_multi_agent_graph

graph = create_multi_agent_graph()
print(graph.get_graph().draw_ascii())
```

## 常见问题

### Token 过期

重新登录获取新 Token。

### 数据库连接失败

```bash
# 检查服务状态
docker compose ps

# 查看日志
docker compose logs postgres
```

### LLM 调用失败

检查 API Key 和网络连接：

```bash
curl https://dashscope.aliyuncs.com/api/v1/services \
  -H "Authorization: Bearer $MODEL_API_KEY"
```
