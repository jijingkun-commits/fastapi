# 文档月度校准清单

> 用途：将文档治理从“临时修复”变为“例行巡检”，避免路径、命令、口径再次漂移。
> 执行频率：每月 1 次（建议每月第一个工作周）。
> 首次建立：2026-02-14。

---

## 1. 执行范围

每月固定校准以下目录：

1. `docs/开发文档/架构设计/`
2. `docs/开发文档/快速入门/`
3. `docs/开发文档/技巧与速查/`
4. `docs/开发文档/代码解读/`

---

## 2. 标准流程

### 2.1 结构与索引校验

```bash
python3 scripts/docs_guard.py --strict
```

通过标准：

1. `errors=0`
2. `summary_coverage=100%`

### 2.2 路径存在性快检

```bash
python3 scripts/docs_guard.py --check-paths
```

通过标准：

1. 不出现关键路径缺失告警（`app/`、`web/`、`scripts/`）
2. 占位示例（如 `xxx_api.py`）不计为失败

### 2.3 口径抽检（最少 3 条）

1. 架构口径：`架构设计/` 与 `代码解读/` 是否存在冲突。
2. 命令口径：速查/工作流是否仍以 `.cursor/commands/*.md` 为权威源。
3. 环境口径：端口、启动方式、测试入口是否与当前脚本一致。

---

## 3. 回填模板

每次执行后，在对应任务文档追加一段：

```text
### 月度校准回填（YYYY-MM-DD）
1. docs_guard --strict：通过/失败（附结果摘要）
2. docs_guard --check-paths：通过/失败（附关键告警）
3. 抽检结论：
   - 架构口径：
   - 命令口径：
   - 环境口径：
4. 待办项（若有）：
```

---

## 4. 责任分工

1. 主责：当月文档 owner（默认当月 WS-G2 owner）
2. 复核：至少 1 名非 owner 协作者
3. 收口标准：回填完成后再进入 `Done`
