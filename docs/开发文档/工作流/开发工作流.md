### 6. 双路径一致性（图片流式传输）

**场景**: 确保实时流和历史数据中的资源 URL 完全一致。

**模式**: 同一数据源，双路径分发 + 兜底修复。

```python
# 工具生成资源
@tool
def fig_inter(...):
    # 1. 生成唯一 URL
    proxy_url = asset_service.get_proxy_url(object_key)
    
    # 2. 路径 1: 实时流式发送
    try:
        writer = get_stream_writer()
        emit_result(writer, "image", {"url": proxy_url})
    except:
        pass  # 非流式上下文忽略
    
    # 3. 路径 2: 返回值（用于数据库持久化）
    return json.dumps({
        "status": "success",
        "image_url": proxy_url  # ⬅️ 同一个 URL
    })
```

```typescript
// 前端去重
const appendImageToAiMessage = (aiId: string, url: string) => {
    const displayedImages = message.additional_kwargs?.displayedImages || [];
    
    // 防止重复显示
    if (displayedImages.includes(url)) return;
```


### 6. LLM as Judge 输出评估模式

**来源**: OpenAI Agents SDK `llm_as_a_judge.py`

**文件**: `app/ai/llm_judge.py`

```python
from app.ai.llm_judge import evaluate_response, iterative_improvement

# 评估 Agent 回复

# result.score: "pass" | "needs_improvement" | "fail"
# result.feedback: "具体的反馈和改进建议"

```

**评估维度**:
- accuracy: 准确性
- completeness: 完整性
- clarity: 清晰度
- relevance: 相关性
