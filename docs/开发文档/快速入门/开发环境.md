## 环境变量配置

### 1. 复制示例文件

```bash
cp .env.example .env.dev
```

### 2. 必须配置的变量

```bash
# 数据库连接
DATABASE_URL=postgresql+psycopg://postgres:password@localhost:5432/chat_db
ANALYTICS_DATABASE_URL=postgresql+psycopg://postgres:password@localhost:5432/data_db

# LLM 配置 (至少配置一个)
QWEN_API_KEY=sk-xxx
DEEPSEEK_API_KEY=sk-xxx
OPENAI_API_KEY=sk-xxx

# MinIO 配置
MINIO_ENDPOINT=localhost:19000
MINIO_ACCESS_KEY=admin
MINIO_SECRET_KEY=12345678

# RAGFlow (可选)
RAGFLOW_API_URL=http://localhost:9380
RAGFLOW_API_KEY=ragflow-xxx
```

### 3. 开发模式特殊配置

```bash
# 开发模式
DEBUG=true
LOG_LEVEL=DEBUG

# 允许跨域
CORS_ALLOW_ORIGINS=http://localhost:3000

# 自动初始化数据库表（仅开发环境）
INIT_DB_ON_STARTUP=true
```

## 启动开发服务

### 方式一：Docker + 本地代码

```bash
# 1. 启动基础设施
docker compose up -d

# 2. 启动后端（新终端）
pip install -e ".[dev]"
uvicorn app.main:app --reload --port 8000

# 3. 启动前端（新终端）
cd web
pnpm install
pnpm dev
```

### 方式二：完全本地

参考 [安装部署](安装部署.md) 中的"方式三"。

### 服务访问地址

启动成功后，可通过以下地址访问各服务：

| 服务 | 地址 | 说明 |
|------|------|------|
| 前端应用 | http://localhost:3000 | 用户界面入口 |
| 管理后台 | http://localhost:3000/admin | 系统管理（需管理员权限） |
| API 文档 | http://localhost:8000/docs | Swagger UI |
| MinIO Console | http://localhost:19001 | 对象存储管理 |

## 常用开发命令

### 后端

```bash
# 启动开发服务器
uvicorn app.main:app --reload

# 运行测试
pytest tests/ -v

# 类型检查
mypy app/

# 代码格式化
ruff format app/

# 数据库结构同步（开发阶段推荐）
bash scripts/db/run_dev_migration.sh

# Alembic（发布前/生产环境）
bash scripts/db/run_release_migration.sh --message "描述" --skip-upgrade
bash scripts/db/run_release_migration.sh --upgrade-only
```

> 说明：日常开发阶段默认使用 `bash scripts/db/run_dev_migration.sh` 即可；只有在发布到测试/生产环境、需要版本化和可回滚时，才补 `bash scripts/db/run_release_migration.sh --message "<message>"` 和 `bash scripts/db/run_release_migration.sh --upgrade-only`。

### 前端

```bash
cd web

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 代码检查
pnpm lint

# 类型检查
pnpm typecheck

# Playwright 测试
pnpm test:e2e
```

### 数据库

```bash
# 一键初始化（推荐）
./deploy.sh dev init
```

手动分步命令统一参考：[初始化命令清单](初始化命令清单.md)。

## 调试技巧

### 后端日志

```bash
# 查看实时日志
tail -f logs/assistant.log

# 过滤 AI 相关日志
tail -f logs/assistant.log | grep -E '\[AI\]|\[Agent\]'
```

### 前端调试

1. 打开浏览器开发者工具
2. Network 面板查看 SSE 事件流
3. Console 面板查看事件处理
4. 页面左下角出现黑色 `N` 图标时，表示当前处于 Next.js 开发模式，图标是 Dev Tools 入口（仅 `pnpm dev` 可见）

### LangSmith 链路追踪

配置环境变量后可在 LangSmith 查看完整 Trace：

```bash
LANGCHAIN_TRACING_V2=true
LANGCHAIN_API_KEY=ls__xxx
LANGCHAIN_PROJECT=fastapi-dev
```

## 常见问题

### PostgreSQL 连接失败

```bash
# 检查服务状态
docker compose ps
# 或
pg_isready -h localhost -p 5432
```

### MinIO 无法访问

```bash
# 检查端口
lsof -i :19000
lsof -i :19001
```

### 前端无法连接后端

1. 确认后端已启动：`curl http://localhost:8000/api/v1/health`
2. 检查 CORS 配置：`CORS_ALLOW_ORIGINS=http://localhost:3000`

### 页面左下角出现 `N` 图标

这是 Next.js Dev Tools（Dev Indicators）入口，只会在本地开发模式显示，生产环境不会出现。

可选处理方式：

1. 临时隐藏：点击 `N` 图标，在 Preferences 中选择 `Hide`
2. 项目级关闭：在 `web/next.config.mjs` 的 `nextConfig` 中增加 `devIndicators: false`，然后重启前端开发服务器

### pgvector 扩展缺失

```sql
-- 在 PostgreSQL 中执行
CREATE EXTENSION IF NOT EXISTS vector;
```
