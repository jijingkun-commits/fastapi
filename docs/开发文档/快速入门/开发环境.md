# 开发环境配置

> 本文档介绍本地开发环境的配置和常用开发命令。

---

## 环境要求

| 组件 | 版本要求 | 用途 |
|------|----------|------|
| Python | ≥ 3.11 | 后端运行时 |
| Node.js | ≥ 18 | 前端运行时 |
| pnpm | ≥ 10.5 | 前端包管理 |
| PostgreSQL | ≥ 16 | 主数据库 |
| MinIO | 最新版 | 对象存储 |

---

## 开发工具推荐

### IDE

- **VSCode / Cursor** (推荐)
  - Python 扩展
  - Pylance (类型检查)
  - ESLint + Prettier

### 数据库工具

- **DBeaver** 或 **pgAdmin** - PostgreSQL 管理
- **MinIO Console** - 对象存储管理 (http://localhost:19001)

## 环境变量配置

### 1. 复制示例文件

```bash
cp .env.example .env.dev
```

### 2. 必须配置的变量

```bash
# 数据库连接
DATABASE_URL=postgresql+psycopg://postgres:password@localhost:5432/chat_db
DATA_DATABASE_URL=postgresql+psycopg://postgres:password@localhost:5432/data_db

# LLM 配置 (至少配置一个)
QWEN_API_KEY=sk-xxx
DEEPSEEK_API_KEY=sk-xxx
OPENAI_API_KEY=sk-xxx

# MinIO 配置
MINIO_ENDPOINT=localhost:19000
MINIO_ACCESS_KEY=admin
MINIO_SECRET_KEY=12345678

# RAGFlow (可选)
RAGFLOW_API_URL=http://localhost:9380
RAGFLOW_API_KEY=ragflow-xxx
```

### 3. 开发模式特殊配置

```bash
# 开发模式
DEBUG=true
LOG_LEVEL=DEBUG

# 允许跨域
CORS_ALLOW_ORIGINS=http://localhost:3000

# 自动初始化数据库表（仅开发环境）
INIT_DB_ON_STARTUP=true
```

## 启动开发服务

### 方式一：Docker + 本地代码

```bash
# 1. 启动基础设施
docker compose up -d

# 2. 启动后端（新终端）
pip install -e ".[dev]"
uvicorn app.main:app --reload --port 8000

# 3. 启动前端（新终端）
cd web
pnpm install
pnpm dev
```

### 方式二：完全本地

参考 [安装部署](安装部署.md) 中的"方式三"。

## 常用开发命令

### 后端

```bash
# 启动开发服务器
uvicorn app.main:app --reload

# 运行测试
pytest tests/ -v

# 类型检查
mypy app/

# 代码格式化
ruff format app/

# 数据库迁移
alembic revision --autogenerate -m "描述"
alembic upgrade head
```

### 前端

```bash
cd web

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 代码检查
pnpm lint

# 类型检查
pnpm typecheck

# Playwright 测试
pnpm test:e2e
```

### 数据库

```bash
# 初始化表结构
python scripts/init_tables_ci.py

# 初始化指标库
python scripts/init_metric_definition.py

# 同步技能向量
python scripts/import_skills.py

# 语义层向量同步
python app/ai/semantic/schema_sync.py
```

## 调试技巧

### 后端日志

```bash
# 查看实时日志
tail -f logs/assistant.log

# 过滤 AI 相关日志
tail -f logs/assistant.log | grep -E '\[AI\]|\[Agent\]'
```

### 前端调试

1. 打开浏览器开发者工具
2. Network 面板查看 SSE 事件流
3. Console 面板查看事件处理

### LangSmith 链路追踪

配置环境变量后可在 LangSmith 查看完整 Trace：

```bash
LANGCHAIN_TRACING_V2=true
LANGCHAIN_API_KEY=ls__xxx
LANGCHAIN_PROJECT=fastapi-dev
```

## 常见问题

### PostgreSQL 连接失败

```bash
# 检查服务状态
docker compose ps
# 或
pg_isready -h localhost -p 5432
```

### MinIO 无法访问

```bash
# 检查端口
lsof -i :19000
lsof -i :19001
```

### 前端无法连接后端

1. 确认后端已启动：`curl http://localhost:8000/health`
2. 检查 CORS 配置：`CORS_ALLOW_ORIGINS=http://localhost:3000`

### pgvector 扩展缺失

```sql
-- 在 PostgreSQL 中执行
CREATE EXTENSION IF NOT EXISTS vector;
```
