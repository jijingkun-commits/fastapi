# 初始化命令清单

> 用途：统一维护数据库/配置/技能初始化命令，避免在多份快速入门文档重复维护。
> 权威范围：`安装部署.md`、`开发环境.md`、`生产部署手册.md` 中的初始化命令段均以本文为准。
> 最后更新：2026-03-12

---

## 1. 一键初始化（推荐）

```bash
./deploy.sh dev init
```

该命令会串行完成：数据库同步、系统配置、指标初始化、技能导入、元数据同步、MinIO 初始化等步骤。

---

## 2. 手动分步初始化（按需）

```bash
bash scripts/db/run_dev_migration.sh           # 开发态数据库迁移统一入口
python scripts/init_llm_config.py              # 初始化 LLM 模型配置
python install/scripts/init_system_config.py   # 初始化系统配置项（AI参数、RAGFlow、问数白名单）
python scripts/init_metric_definition.py       # 初始化指标定义
python scripts/expand_metrics.py               # 扩展指标
python scripts/import_skills.py                # 导入 AI 技能
python scripts/schema_sync.py                  # 元数据同步（从 Analytics DB 导入表结构）
python -m app.ai.semantic.schema_sync          # 语义向量同步（embedding）
python install/scripts/init_minio_buckets.py   # 初始化 MinIO Bucket
```

---

## 3. 仅迁移/补丁场景

```bash
./deploy.sh dev migrate
./deploy.sh prod migrate
```

说明：存量环境优先走 `migrate`，避免重复执行全量初始化。
