# 安装部署

本文档介绍如何在本地开发环境或生产环境中部署项目。

## 系统要求

| 组件 | 版本要求 |
|------|----------|
| Python | ≥ 3.11 |
| Node.js | ≥ 18 (前端) |
| pnpm | ≥ 10.5.1 (前端包管理) |
| PostgreSQL | **≥ 16** (需安装 `pgvector` 扩展用于问数功能) |
| MinIO | 最新版 |

---

## 方式一：Docker Compose（推荐）

最快速的启动方式，自动配置所有依赖服务。

### 1. 克隆项目

```bash
git clone <repo-url>
cd fastapi
```

### 2. 配置环境变量

```bash
cp .env.example .env.dev
# 编辑 .env.dev，配置必要参数（参考 [配置说明](配置说明.md) 章节）
```

### 3. 启动基础设施

```bash
# 仅启动 PostgreSQL + MinIO（开发模式）
docker compose up -d

# 查看服务状态
docker compose ps
```

服务启动后：
- **PostgreSQL**: `localhost:5432`
- **MinIO API**: `localhost:19000`
- **MinIO Console**: `localhost:19001` (用户名: admin, 密码: 12345678)

### 4. 初始化数据库和服务

```bash
# 安装 Python 依赖
pip install -e ".[dev]"

# 一键初始化（推荐）
./deploy.sh dev init
```

一键初始化会自动完成：
- 创建数据库表结构
- 执行增量迁移脚本
- 初始化 LLM 模型配置
- 初始化指标定义
- 同步表元数据
- 初始化 MinIO Bucket
- 导入 AI 技能

如需手动分步执行：

```bash
python scripts/sync_database.py          # 同步数据库表结构
python scripts/init_llm_config.py        # LLM 配置
python scripts/init_metric_definition.py # 指标定义
python scripts/expand_metrics.py         # 扩展指标
python scripts/import_skills.py          # AI 技能
python scripts/schema_sync.py            # 元数据同步
python install/scripts/init_minio_buckets.py  # MinIO Bucket
```

### 5. 启动后端

```bash
uvicorn app.main:app --reload --port 8000
```

### 6. 启动前端

```bash
cd web
pnpm install
pnpm dev
```

前端访问地址：`http://localhost:3000`

## 方式二：完整容器部署

启动包含应用服务的完整容器集群。

```bash
# 启动所有服务（基础设施 + 应用）
docker compose --profile app up -d
```

服务列表：
- **后端 API**: `http://localhost:8000`
- **前端 Web**: `http://localhost:3000`
- **PostgreSQL**: `localhost:5432`
- **MinIO**: `localhost:19000`

## 方式三：本地开发（无 Docker）

### 1. 安装 PostgreSQL

```bash
# macOS
brew install postgresql@16
brew services start postgresql@16

# 创建数据库
createdb chat_db

# 启用 pgvector 扩展（问数功能必需）
psql -d chat_db -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

### 2. 安装 MinIO

```bash
# macOS
brew install minio/stable/minio
minio server ~/minio-data --console-address ":9001"
```

### 3. 配置环境变量

```bash
cp .env.example .env.dev
# 根据实际情况修改 DATABASE_URL、MINIO_ENDPOINT 等
```

### 4. 初始化数据库和服务

```bash
# 安装 Python 依赖
pip install -e ".[dev]"

# 一键初始化（推荐）
./deploy.sh dev init
```

或手动分步执行：

```bash
# 执行全量建表 SQL
psql -d chat_db -f install/sql/init_postgres.sql

# 初始化配置和数据
python scripts/sync_database.py          # 同步数据库表结构
python scripts/init_llm_config.py        # LLM 配置
python scripts/init_metric_definition.py # 指标定义
python scripts/expand_metrics.py         # 扩展指标
python scripts/import_skills.py          # AI 技能
python scripts/schema_sync.py            # 元数据同步

# 初始化 MinIO Bucket
python install/scripts/init_minio_buckets.py
```

### 5. 启动服务

```bash
# 后端
uvicorn app.main:app --reload

# 前端（新终端）
cd web && pnpm install && pnpm dev
```

## 部署脚本说明

项目提供 `deploy.sh` 一键部署脚本，支持多种操作：

```bash
./deploy.sh [环境] [操作]

# 环境: dev | prod (默认: dev)
# 操作: init | migrate | start | stop | restart | status | logs
```

常用命令：

| 命令 | 说明 |
|------|------|
| `./deploy.sh dev init` | 初始化开发环境（数据库、MinIO、技能） |
| `./deploy.sh dev start` | 启动开发服务 |
| `./deploy.sh prod migrate` | 生产环境数据库迁移 |
| `./deploy.sh dev status` | 查看服务状态 |

> **脚本位置**: 项目根目录 `deploy.sh`

## 生产部署注意事项

### 环境变量

生产环境需要使用 `.env.prod` 配置：

```bash
# 必须修改的配置
JWT_SECRET=<生成一个强随机字符串>
DATABASE_URL=postgresql+psycopg://user:password@host:5432/dbname
CORS_ALLOW_ORIGINS=https://your-domain.com
```

### 安全配置

- 禁用 `INIT_DB_ON_STARTUP`
- 设置强随机 `JWT_SECRET`
- 配置 CORS 白名单
- 使用 HTTPS

### 日志配置

```bash
LOG_LEVEL=INFO
LOG_FILE=logs/assistant.log
```

## 常见问题

### PostgreSQL 连接失败

确认数据库服务已启动：
```bash
docker compose ps  # Docker 模式
pg_isready         # 本地模式
```

### MinIO 无法访问

检查端口是否被占用：
```bash
lsof -i :19000
```

### 前端无法连接后端

确认后端 CORS 配置：
```bash
# .env.dev
CORS_ALLOW_ORIGINS=http://localhost:3000
```

## AI Skills RAG 配置与同步

本项目集成了 **Agent Skills RAG** 机制，允许 AI 在运行时动态检索业务技能。

### 1. 数据库准备

确保已安装 `pgvector` 扩展并执行了最新的数据库迁移：

```bash
# 激活虚拟环境
python scripts/init_tables_ci.py  # 初始化表结构（含 t_agent_skills）

# 或者手动执行 Alembic
alembic revision --autogenerate -m "add_t_agent_skills"
alembic upgrade head
```

### 2. 配置 Embedding 模型

AI 技能检索依赖向量化模型。请确保在数据库 (`t_llm_models`) 中配置了 **Embedding 模型**：

- **Provider**: `zhipu` (推荐) 或 `openai`
- **Model Type**: `embedding`
- **Model Name**: `embedding-3` (智谱，1024维)

### 3. 初始化/更新技能库

当添加或修改 `app/ai/skills/` 目录下的 `SKILL.md` 文件后，需运行同步脚本：

```bash
# 全量导入/更新（自动检测变更）
python scripts/import_skills.py

# 强制重新导入所有技能
python scripts/import_skills.py --force

# 指定技能目录（可选）
python scripts/import_skills.py --source /path/to/custom_skills
```

> **提示**: 应用启动时也会尝试自动增量同步，但在生产环境中建议使用脚本手动触发以确保可控。

### 4. 验证安装

在聊天窗口输入指令验证：
> "帮我记录一个待办"

检查后端日志，若出现以下内容则说明 RAG 检索正常：
```text
[INFO] 预处理节点: 检索到 1 个相关技能: ['knowledge-search']
```
