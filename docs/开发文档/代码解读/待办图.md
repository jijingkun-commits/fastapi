## 状态结构

```python
class TodoAgentState(TypedDict):
    messages: Annotated[List[BaseMessage], add_messages]
    user_id: Optional[int]
    thread_id: Optional[str]
    pending_operation: Optional[Dict]  # {action, data, needs_clarification, skip_confirmation}
    user_confirmed: Optional[bool]
    quick_mode: Optional[bool]
    extracted_info: Optional[Dict]
    pending_clarifications: Optional[List[str]]
```

## 图流程

```
analyze → route_next → [clarify|conflict|resolve|execute]
                              │
                              ▼
                        route_after_resolve
                              │
                    [clarify|confirm|execute]
                              │
                              ▼
                        wait_confirm
                              │
                              ▼
                           execute
```

---

## 核心节点

### analyze_intent

分析用户意图，返回 `pending_operation`:

```python
{
    "action": "create|update|delete|query|...",
    "data": {"title": "...", "due_date": "..."},
    "needs_clarification": False,
    "skip_confirmation": False
}
```

### resolve_entity

将模糊标识解析为 `todo_id`:

```python
# 输入: data.title = "那个会议"
# 输出: data.todo_id = 123, data.resolved_title = "明天的项目会议"
```

### wait_for_confirmation

使用 `interrupt()` 暂停等待用户确认:

```python
decision = interrupt({
    "action_requests": [{"name": action, "args": data}]
})
# 前端 resume 时传入 {confirmed: True/False}
```

---

## 路由规则

| 条件 | 路由目标 |
|-----|---------|
| `pending_op.skip_confirmation` | execute |
| `pending_op.needs_clarification` | clarify |
| 有 `pending_op` | resolve |
| 无操作 | clarify |
