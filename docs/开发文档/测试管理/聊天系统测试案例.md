## 2. 基础对话测试

### TC-CHAT-01: 流式响应首 Token

| 属性 | 值 |
|-----|---|
| **前置条件** | 用户已登录，后端正常 |
| **输入** | “你好” |
| **预期行为** | 2 秒内出现首字符；过程中有“正在输入”指示 |
| **验证方法** | 记录发送时间与首字符出现时间差 |

### TC-CHAT-02: 对话历史持久化

| 属性 | 值 |
|-----|---|
| **前置条件** | 已发送至少 3 条消息 |
| **操作** | 刷新页面 |
| **预期行为** | 历史消息完整显示，顺序一致 |

### TC-CHAT-03: 多轮上下文保持

| 属性 | 值 |
|-----|---|
| **前置条件** | 同一对话线程 |
| **输入** | 先发送“我下午有会议”，再发送“它几点开始？” |
| **预期行为** | AI 能理解“它”指代上一轮内容 |

### TC-CHAT-04: 停止与反馈

| 属性 | 值 |
|-----|---|
| **前置条件** | AI 正在生成回复 |
| **操作** | 点击“停止”，并进行点赞/点踩 |
| **预期行为** | 生成被中断；反馈被记录 |
