## 6. 权限与安全测试

### TC-ADMIN-05: 非管理员访问拦截

| 属性 | 值 |
|-----|---|
| **关联需求** | `docs/产品文档/管理后台需求.md` 中的后台访问控制与治理权限约束 |
| **关联设计** | `docs/开发文档/架构设计/后端架构.md` 中的鉴权、角色校验与后台接口分层 |
| **风险标签** | `role`, `authz`, `ui-api-consistency`, `audit` |
| **风险等级** | P0 |
| **前置条件** | 使用普通用户账号登录 |
| **输入 / 触发** | 1. 直接访问 `/admin` 页面 URL<br>2. 直接调用后台治理 API |
| **主结果断言** | 页面访问被拒绝（跳转首页或显示无权限），API 调用返回 403 Forbidden |
| **失败语义断言** | 不得通过“页面隐藏但接口可调”或“接口拒绝但页面仍展示缓存数据”的方式泄露后台信息 |
| **状态 / 副作用断言** | 非管理员访问不得暴露后台页面内容、配置快照、总览指标或调试入口；若系统记录拒绝事件，应具备可审计轨迹 |
| **验证方法** | `curl -H "Authorization: Bearer {user_token}" /api/v1/admin/config` — 应返回 403 |
| **历史缺陷来源** | 前后端鉴权不一致时，最容易出现“页面拦了、接口没拦”或反之 |
| **退化信号** | 普通用户能看到后台菜单、访问总览卡片、或从接口拿到治理数据 |
