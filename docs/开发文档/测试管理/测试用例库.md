# 测试用例库 (Test Case Repository)

本文档作为系统的核心测试资产，记录所有关键功能的验证方法、预期结果及自动化覆盖情况。修改功能或修复 Bug 后，请基于此文档进行回归测试。

## 测试生命周期 (Testing Lifecycle)
遵循 **"使用 -> 验证 -> 沉淀"** 的闭环流程：
1.  **使用 (Use)**: 在开发新功能或修复 Bug 前，查阅此文档确认已有测试用例。
2.  **验证 (Verify)**: 执行测试，确保功能符合预期。**注意：E2E 测试数据需保留，禁止自动清理，以便进行人工数据审计。**
3.  **沉淀 (Sediment)**: 将新发现的边界条件、有效用例补充回此文档，并将自动化脚本标记为 ✅。

## 4. 测试分层策略

- **L1 单元测试 (Unit)**: 针对纯函数逻辑 (如 Prompt 模板生成、数据解析)。
- **L2 集成测试 (Integration)**: 针对数据库交互、Service 层逻辑 (如 `test_todo_db_integration.py`)。必须在 CI 中运行。
- **L3 端到端测试 (E2E)**: 针对完整用户场景 (如 Playwright 测试)。覆盖核心路径。
