# 脚本链路证据注册表

> 用途：为 `/jjk-test` 的 `Scripted Flow Status` 提供唯一可追溯清单。  
> 适用范围：命中 `mandatory_evidence` 包含 `scripted_flow` 的任务。  
> 最后更新：2026-03-08

---

## 1. 报告对账字段（强制）

每次测试报告至少包含以下字段：

1. `Required Evidence`
2. `Actual Evidence`
3. `Scripted Flow Status`
4. `Historical Gap vs Current Gap`

若脚本链路缺失导致 `mandatory_evidence` 未满足，输出失败码：`TEST_DB_CHAIN_INCOMPLETE`。

---

| SF-ENV-001 | `tests/verify_environment.py` | `env_gate` | `scripted_flow` | 环境前置门禁全部通过 |

---

## 3. 维护规则

1. 新增脚本链路时必须先登记 Script ID，再纳入测试矩阵。
2. `Actual Evidence` 需引用结构化结果（如 `acceptance_results[*].kind/cmd/exit_code/summary`）。
3. 允许记录历史缺口，但不得将历史缺口冒充本轮已验证。
4. 命中 DB 风险任务时，脚本链路仅是补充证据，不能替代 DB 断言证据本身。
