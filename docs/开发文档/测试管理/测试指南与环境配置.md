## 3. 运行测试

### 后端测试

```bash
# 安装测试依赖
pip install -e ".[dev]"

# 运行所有测试
pytest

# 运行特定测试
pytest app/tests/test_todo.py

# 显示详细输出
pytest -v
```

### 前端 E2E 测试

```bash
cd web

# E2E 测试
npm run test:e2e

# 有界面模式
npm run test:e2e:ui
```

### AI 对话测试

```bash
# API 模式测试（10轮复杂对话）
python test_todo_api.py

# 意图分析测试（无需数据库）
python test_todo_stress.py --analyze

# Playwright E2E 测试
cd web && npx playwright test e2e/todo_agent_stress_test.spec.cjs
```

## 7. 常见问题与修复

### 7.1 环境配置问题

| 问题 | 症状 | 修复方案 |
|------|------|---------|
| 前后端端口不匹配 | 前端发送请求失败 | 修改 `web/.env` 中 `NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8089` |
| Pydantic V2 迁移 | `ImportError: cannot import BaseSettings` | 改为 `from pydantic_settings import BaseSettings` |
| 模块导入冲突 | `module has no attribute 'STREAMING'` | 在 `__init__.py` 中重新导出常量 |

### 7.2 路由问题排查

当待办请求未被正确路由时：

1. **检查后端日志**
   ```bash
   tail -f logs/assistant.log | grep -E "(supervisor|todo_expert)"
   ```

2. **检查 Supervisor Prompt**
   - 文件: `app/ai/prompts/agent_prompts.py`
   - 确认决策树中"待办事项管理"节点存在

3. **恢复原始代码**
   ```bash
   git checkout app/ai/prompts/agent_prompts.py
   git checkout app/ai/workflow/multi_agent_graph.py
   ```

### 7.3 调试原则

> **先检查配置和 Prompt，再考虑修改代码架构。**

| 顺序 | 检查项 | 说明 |
|------|--------|------|
| 1 | 服务状态 | `curl http://localhost:8089/health` |
| 2 | 端口配置 | `web/.env` 与后端端口一致 |
| 3 | Prompt 文件 | 核心决策树未被修改 |
| 4 | 代码逻辑 | 最后考虑修改架构 |
