## 3. 命名规范

- 允许的主报告命名：`{模块名}测试报告.md`
- 允许的归档命名（无分隔日期）：`{模块名}测试报告_YYYYMMDD_{主题}.md`
- 允许的归档命名（短横线日期）：`{模块名}测试报告_YYYY-MM-DD_{主题}.md`

命名约束：
- 归档文件必须带 `{主题}` 后缀，不允许只写日期。
- 统一使用“模块名在前”的命名，不再使用 `测试报告_{场景}_{日期}.md` 兼容格式。

反例（禁止新增）：
- `测试报告_对话同步_20260130.md`
- `用户管理测试报告_2026-02-03.md`

新增/重命名测试报告后，必须同步：
- `docs/SUMMARY.md` 的入口链接
- `docs/开发文档/测试管理/测试用例库.md` 的“详细报告”链接
- 本文件中的主报告/归档表格
