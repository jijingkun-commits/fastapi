## 6. API 测试用例

### 6.1 用户列表 API

```bash
# 正常请求
GET /api/v1/users?page=1&page_size=10
Authorization: Bearer {admin_token}
# 预期: 200, 返回分页用户列表

# 无权限请求
GET /api/v1/users
# 预期: 401
```

### 6.2 创建用户 API

```bash
POST /api/v1/users
Authorization: Bearer {admin_token}
Content-Type: application/json
{
  "username": "newuser",
  "password": "password123",
  "role": "user",
  "data_role": "staff",
  "org_code": "ORG001",
  "dept_code": "D001"
}
# 预期: 201, 返回新用户信息（含 role/data_role）
```

### 6.3 禁用/启用用户 API

```bash
PATCH /api/v1/users/{id}/status
Authorization: Bearer {admin_token}
Content-Type: application/json
{"is_active": false}
# 预期: 200, 返回更新后的用户信息
```

### 6.4 登出 API

```bash
POST /api/v1/logout
Authorization: Bearer {user_token}
# 预期: 200, {"message": "登出成功"}
```

### 6.5 批量删除对话 API

```bash
DELETE /api/v1/chat/threads/batch
Authorization: Bearer {user_token}
Content-Type: application/json
{"thread_ids": ["id1", "id2"]}
# 预期: 200
```

### 6.6 双角色权限属性 API

```bash
# 查询用户列表（关注 role/data_role 字段）
GET /api/v1/users?page=1&page_size=10
Authorization: Bearer {admin_token}
# 预期: 200, items[] 包含 role/data_role/org_code/dept_code

# 创建用户（不传 data_role，验证默认值）
POST /api/v1/users
Authorization: Bearer {admin_token}
Content-Type: application/json
{
  "username": "staff_auto",
  "password": "password123",
  "role": "user"
}
# 预期: 201, data_role 默认 staff
```
