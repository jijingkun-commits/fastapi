# 编码与文档规范

> 项目编码和文档规范，确保代码与文档风格一致性。

---

## 1. 通用规则

- **所有注释使用中文**
- 思考和输出使用中文
- 遵循 **"文档即代码"** 理念

### 项目规则文件结构

| 文件 | 用途 | 说明 |
|------|------|------|
| `PROJECT_RULES.md` | 共有规则真源 | 所有 AI 工具共享的项目规范 |
| `CLAUDE.md` | Claude Code 规则入口 | 软链接到 `PROJECT_RULES.md` |
| `AGENTS.md` | Cursor / Codex 补充规则 | 仅包含 Cursor/Codex 特有内容（规则来源映射、命令兼容、技能目录） |
| `.cursor/rules/*.mdc` | Cursor 细粒度规则 | 按场景自动加载 |

修改项目规则时，统一编辑 `PROJECT_RULES.md`；Cursor/Codex 特有内容编辑 `AGENTS.md`。

## 2. Python 规范

### 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 文件名 | snake_case | `chat_service.py` |
| 类名 | PascalCase | `ChatService` |
| 函数/变量 | snake_case | `get_user_by_id` |
| 常量 | UPPER_SNAKE_CASE | `MAX_RETRY_COUNT` |

### 类型提示

必须使用 Type Hints：

```python
from typing import Optional, List

def get_todos(user_id: int, status: Optional[str] = None) -> List[Todo]:
    ...
```

### 模块文档

每个模块顶部必须包含 docstring：

```python
"""待办服务模块（中文说明）。

提供待办事项的业务逻辑处理。
"""
```

### ORM 模型

使用 SQLAlchemy 2.0 语法：

```python
class Todo(Base):
    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(500), nullable=False)
```

## 3. TypeScript 规范

### 类型定义

严格使用 TypeScript，避免 `any`：

```typescript
interface Todo {
  id: number;
  title: string;
  status: 'todo' | 'in_progress' | 'done';
}
```

### 组件命名

- 组件文件：PascalCase（`ChatInput.tsx`）
- Hook 文件：camelCase（`useSSEStream.ts`）

---

## 4. 数据库规范

- 表名以 `t_` 开头
- 字段使用 snake_case
- 主键统一为 `id`

## 5. 文档编写规范

### 文档分类

| 分类 | 目录 | 读者对象 |
|------|------|----------|
| 产品文档 | `docs/产品文档/` | 用户/产品 |
| 开发文档 | `docs/开发文档/` | 开发者 |
| API 文档 | `docs/API文档/` | 前后端对接 |
| 内部参考 | `docs/内部参考/` | AI/团队 |

### 工作流集成

- **`/jjk-plan`**: 产出 `requirements.md`，定义用户故事和验收标准
- **`/jjk-imp`**: 代码实现，同时更新相关文档
- **`/jjk-test`**: 读取 `requirements.md` 生成测试用例

### 架构决策记录 (ADR)

遇到重大技术选型时，记录在 `内部参考/决策记录.md`：
- **背景**: 为什么要做这个决定？
- **决策**: 做了什么决定？
- **后果**: 带来了什么影响？

### 必须使用 Mermaid

架构和流程图必须使用 Mermaid 绘制，便于版本追踪。

### 提交前文档校验

文档相关改动提交前建议执行：

```bash
python3 scripts/docs_guard.py --strict
```

如需在 CI 或脚本中消费结果，可输出 JSON 报告：

```bash
python3 scripts/docs_guard.py --json-out /tmp/docs_guard_report.json
```

功能开发完成必须满足：

- [ ] 相关产品文档已更新
