## 关于本仓库

本着文档先行的理念，将项目的文档进行公开，如果有大佬能够给出一些指导、指出一些问题（我好完善和对项目进行改进），感激不尽。

公开文档的目的，是希望读者仅通过文档就能了解项目的大多数细节——从产品需求、架构设计、开发规范到测试案例，力求做到文档的全面性，让"不看代码也能看懂项目"成为可能。

当前仓库同时包含后端、前端与文档；`docs/` 目录是文档主入口，供学习与协作时快速查阅。

若你只关注文档内容，可直接从本页和 `SUMMARY.md` 开始阅读，无需先通读代码。

> **声明**：文档中出现的企业名称、Logo 及品牌元素均为虚构或借用于网络，仅用于学习演示目的，不代表与任何真实企业存在关联。如有侵权，请联系删除。

## 关于本项目

本项目是一个从零开始、一点一滴完善的 AI 应用，主要目的是**学习 AI 应用开发**。除知识库部分集成了开源的 [RAGFlow](https://github.com/infiniflow/ragflow) 外，其余所有模块（多智能体工作流、对话系统、待办助手、数据问答引擎、管理后台、前端界面等）均借助 Vibe Coding 的方式从零完成——在 AI 辅助编程日趋成熟的当下，一个人也能搭出一套完整的系统。

项目能否真正达到企业级落地的标准，犹未可知。但整个开发过程中积累的设计思路、踩坑经验和技术方案，大都记录在了这份文档中。文档中也分享了少许 Vibe Coding 的实践心得——如何驾驭工具、如何指导 AI 工作、如何向 AI 学习，希望对同样在探索 AI 辅助开发的朋友有所帮助。

当有了工具和算力之后，对架构和逻辑实现的思考会变得更重要，很多事情需要自己想清楚才能更好的实现。
**关于成本**：本项目在构建过程中，在 Token 消耗上也投入了真金白银——累计花费**将近 2000 人民币**。这还是在精打细算的情况下（Claude 3 Opus 实在太贵了，如果全用它，成本估计得接近 5000 美刀...），这也印证了 Vibe Coding 虽然高效，但"燃料"也是必不可少的。(这种情况今后可能还会有变化，因为现在的模型差距特别特别特别大，便宜的就跟刚刚来上班的实习生已读乱回，贵的opus比你强还比你情绪稳定，今后发展到大家都达到很高的水平之后，充分竞争应该会大价格打下来。)
