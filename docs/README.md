## 文档结构

```
docs/
├── 项目上下文.md        ← 新对话快速入口
├── README.md           ← 本阅读指南
├── SUMMARY.md          ← 完整目录
│
├── 产品文档/            ← 功能说明 (用户/产品)
│   ├── 产品概述.md
│   ├── 聊天系统.md
│   ├── 待办助手.md
│   └── 数据分析.md
│
├── 开发文档/            ← 开发指南 (开发者)
│   ├── 快速入门/        ← 新手从这里开始
│   │   ├── 安装部署.md
│   │   ├── 快速开始.md
│   │   ├── 配置说明.md
│   │   └── 开发环境.md
│   ├── 架构设计/        ← 系统设计详解
│   │   ├── 系统总览.md
│   │   ├── AI模块设计.md
│   │   └── ...
│   ├── 代码解读/        ← 深入实现细节
│   ├── 规范/            ← 编码规范
│   ├── 工作流/          ← 开发工作流
│   ├── 测试管理/        ← 测试相关
│   └── 技巧与速查/      ← 调试技巧
│
├── API文档/             ← 接口对接 (前后端)
│   ├── 接口文档.md
│   └── 外部服务集成.md
│
└── 内部参考/            ← 团队内部 (AI/决策)
    ├── 决策记录.md
    ├── AI技能库.md
    ├── 数据资料/        ← 仅保留指南文档
    └── 迭代需求/        ← 当前冲刺需求
```

## 文档维护规则

代码修改时必须同步更新文档：

| 修改范围 | 更新文档 |
|---|---|
| 新增功能 | `产品文档/产品概述.md` |
| API 变更 | `API文档/接口文档.md` |
| AI 模块 | `开发文档/架构设计/AI模块设计.md` |
| 数据库 | `开发文档/架构设计/数据库设计.md` |
| 配置项 | `开发文档/快速入门/配置说明.md` |

详见 `.cursor/rules/doc_first.md`。
