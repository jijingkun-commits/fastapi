# 管理后台需求文档

> 版本: 1.0  
> 更新时间: 2026-02-01  
> 范围: 统一管理后台配置与管理能力

## 访问入口

| 环境 | 地址 |
|------|------|
| 开发环境 | http://localhost:3000/admin |
| 生产环境 | `{域名}/admin` |

## 1. 角色与场景

- **管理员**：管理系统配置、模型配置、数据访问控制、技能管理

## 2. 用户故事与验收标准

### US-ADMIN-01: 数据访问控制管理

**角色**：作为管理员  
**需求**：我想查看和验证数据访问白名单/黑名单  
**目的**：以便控制可访问的数据范围

**验收标准**：
- AC-1: 在访问控制页面可查看白名单/黑名单列表
- AC-2: 可通过"测试 SQL"验证允许/拒绝行为
- AC-3: 白名单/黑名单数据与后端接口一致

**关联测试**：TC-ADMIN-01

### US-ADMIN-02: LLM 配置管理

**角色**：作为管理员  
**需求**：我想查看并管理模型提供商与模型列表  
**目的**：以便切换或校验系统默认模型

**验收标准**：
- AC-1: 提供商列表展示完整且 API Key 脱敏
- AC-2: 模型列表包含类型/状态/元信息
- AC-3: 修改默认模型后，新对话使用新的默认模型

**关联测试**：TC-ADMIN-02

### US-ADMIN-03: 技能管理

**角色**：作为管理员  
**需求**：我想查看技能列表与向量状态  
**目的**：以便确认技能可用性

**验收标准**：
- AC-1: 技能列表可检索并展示关键信息
- AC-2: 向量状态异常时有明确提示

**关联测试**：TC-ADMIN-03

### US-ADMIN-04: 系统配置管理

**角色**：作为管理员  
**需求**：我想查看并编辑系统配置  
**目的**：以便调整运行参数

**验收标准**：
- AC-1: 配置项可按分类筛选
- AC-2: 配置项可编辑并保存生效

**关联测试**：TC-ADMIN-04

## 3. 非功能需求

- **安全**：管理员页面需鉴权访问
- **可用性**：配置编辑失败需提示原因并可重试
