> 更新时间: 2026-02  
> 范围: 统一管理后台配置与管理能力

## 访问入口

| 环境 | 地址 |
|------|------|
| 开发环境 | http://localhost:3000/admin |
| 生产环境 | `{域名}/admin` |

## 1. 角色与场景

- **管理员**：管理系统配置、模型配置、数据访问控制、技能管理

## 2. 用户故事与验收标准

### US-ADMIN-01: 数据访问控制管理

**角色**：作为管理员  
**需求**：我想查看和验证数据访问白名单/黑名单  
**目的**：以便控制可访问的数据范围

**验收标准**：
- AC-1: 在访问控制页面可查看白名单/黑名单列表
- AC-2: 可通过"测试 SQL"验证允许/拒绝行为
- AC-3: 白名单/黑名单数据与后端接口一致

**关联测试**：TC-ADMIN-01

### US-ADMIN-02: LLM 配置管理

**角色**：作为管理员  
**需求**：我想查看并管理模型提供商与模型列表  
**目的**：以便切换或校验系统默认模型

**验收标准**：
- AC-1: 提供商列表展示完整且 API Key 脱敏
- AC-2: 模型列表包含类型/状态/元信息
- AC-3: 修改默认模型后，新对话使用新的默认模型

**关联测试**：TC-ADMIN-02

### US-ADMIN-05: 模型路由管理

**角色**：作为管理员  
**需求**：我想在「模型路由」Tab 中查看和修改各场景使用的模型  
**目的**：以便为不同场景匹配合适的模型，提高速度、降低 token 消耗、提高准确度

**路由分层（按能力需求）**：

| 场景 | 调用点 | 配置方式 | 推荐模型 |
|------|--------|---------|---------|
| 主对话 | Supervisor / Agent 回复 | 聊天页模型选择器（用户自选） | 用户按需选择 |
| SQL 生成 / 内部分析 | vanna_client, analyze_data_intent, todo analyze_intent | `t_system_config` 键: `model_routing.sql_generation` | qwen-plus / deepseek-chat |
| 轻量任务 | intent_classifier, parameter_extractor, llm_judge, sql_evaluator | `t_system_config` 键: `model_routing.lightweight` | glm-4.5-air / qwen-flash |
| Embedding | embedding_util | `t_llm_model` 表 type=embedding 默认模型 | embedding-3 |
| Vision | vision_tool | `t_llm_model` 表 type=vision 默认模型 | qwen3-vl-flash |

**验收标准**：
- AC-1: 模型路由 Tab 展示 5 行场景路由表
- AC-2: 「可配置」类场景（SQL 生成/内部分析、轻量任务）提供下拉选择器，可从已启用的 chat 模型中选择并保存
- AC-3: 保存后无需重启服务，配置立即生效（持久化到 `t_system_config` 表，自动刷新内存缓存）
- AC-4: 「用户选择」和「专用模型」类场景为只读展示，不可编辑
- AC-5: 未在数据库配置时，系统回退到环境变量默认值（`SQL_GENERATION_MODEL`、`INTENT_CLASSIFIER_MODEL`）

**业务场景**：
- 推理模型在 SQL 生成中浪费大量 thinking tokens，使用标准模型可节省 50%+ 成本
- 轻量任务（意图分类/参数提取）使用轻量模型，速度提升 2-3 倍，token 消耗降低 80%+

**关联测试**：TC-ADMIN-05  
**设计决策**：见 ADR-010（`docs/内部参考/决策记录.md`）

### US-ADMIN-06: 指标管理

**角色**：作为管理员  
**需求**：我想在管理后台管理问数指标定义，包括查看统计、批量转换 ETL 模板  
**目的**：以便持续扩充问数助手的指标库，提高指标匹配命中率

**功能描述**：
- 管理后台提供"指标管理"页面（路由 `/admin/metrics`）
- 页面顶部展示指标模板统计仪表盘：
  - 数字卡片：总指标数、可查询数（query_template 非空）、未处理数、已向量化数
  - 饼图：模板来源分布（手动 SELECT / 结果表查询 / AI 提取 / 未处理）
  - 柱状图：指标分类分布
  - 明细表：模板类型分布（ETL/SELECT/NULL 及占比）
- 支持指标 CRUD：列表（搜索/筛选/模板状态标签）、新建、编辑、删除
- 新建指标支持两种模式：
  - **手动填写**：直接填写指标 ID、名称、别名、描述、SQL 模板、分类、单位
  - **AI 转换**：粘贴 ETL 批处理脚本，AI 自动提取核心 SELECT 查询模板并推断指标元信息
- **批量转换**：支持两种模式
  - 结果表查询模式（快速，无需 LLM）：自动生成 `SELECT ... FROM f_mid_index_result WHERE index_code=...` 格式查询
  - AI 提取模式（较慢）：使用 LLM 从 ETL 脚本提取 SELECT 查询逻辑
- AI 转换后必须经过人工审核确认才保存
- 创建/更新指标时自动生成 embedding 向量，供语义匹配使用

**验收标准**：
- AC-1: 管理后台首页有"指标管理"入口，路由到 `/admin/metrics`
- AC-2: 统计仪表盘正确展示各维度数据（数字卡片 + 饼图 + 柱状图 + 明细表）
- AC-3: 指标列表支持按分类筛选和关键词搜索
- AC-4: 指标列表展示模板状态标签（可查询/ETL/无）
- AC-5: 粘贴 ETL 脚本后可自动提取 SELECT 模板和指标元信息
- AC-6: AI 转换结果可编辑，确认后才保存到数据库
- AC-7: 批量转换支持预览和执行，展示处理结果
- AC-8: 新建指标后在问数助手中可被匹配到

**关联测试**：TC-ADMIN-06

## 3. 非功能需求

- **安全**：管理员页面需鉴权访问
- **可用性**：配置编辑失败需提示原因并可重试
