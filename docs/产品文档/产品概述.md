## 产品简介

**智能助手** 是一个基于多智能体架构的 AI 助手系统，支持自然语言交互、智能待办管理和数据分析可视化。

## 核心功能

### 1. 智能聊天

- **多模型支持**: OpenAI、Claude、DeepSeek 等主流模型
- **流式响应**: 实时显示 AI 回答，无需等待
- **多轮对话**: 保持上下文，连续追问
- **安全护栏**: 输入/输出内容审查

### 2. 待办助手

| 功能 | 说明 |
|------|------|
| 自然语言创建 | "明天下午3点开会" → 自动创建待办 |
| 智能确认 | 操作前展示确认卡片，避免误操作 |
| 周期任务 | 支持每日/每周/每月重复任务 |
| 多维度查询 | 按时间、优先级、分类筛选 |

### 3. 数据分析

| 功能 | 说明 |
|------|------|
| 自然语言查询 | "本月销售额是多少？" → 自动生成 SQL |
| 自动可视化 | 根据数据自动选择图表类型 |
| 指标匹配 | 业务指标库支持模糊匹配 |

### 4. 知识问答

- **RAGFlow 集成**: 对接企业知识库
- **图片理解**: 支持上传图片进行内容分析

### 5. 管理后台

系统提供 Web 管理界面，用于配置和管理各项功能：

| 模块 | 功能 | 访问地址 |
|------|------|---------|
| 系统配置 | AI、RAGFlow、MCP 等运行参数管理 | `/admin/system` |
| LLM 配置 | 模型提供商和模型的增删改查、默认模型设置 | `/admin/llm` |
| 技能管理 | Agent 技能库维护、向量索引重建 | `/admin/skills` |
| 数据访问控制 | 问数功能的表白名单/黑名单配置 | `/admin/access` |

## 系统架构

### 请求处理流程

```mermaid
sequenceDiagram
    participant User as 用户 (前端)
    participant API as chat_api.py
    participant Service as ChatService
    participant Graph as MultiAgentGraph
    participant Tool as Tools
    participant Repo as Repositories
    participant DB as PostgreSQL

    User->>API: POST /api/v1/chat/stream
    API->>Service: sse_stream()
    Service->>Graph: astream()
    
    loop SSE 事件循环
        Graph->>Service: yield events
        Service->>User: SSE: token/tool_start/tool_end
    end
    
    Graph->>Tool: 调用工具 (如 add_todo)
    Tool->>Repo: 数据操作
    Repo->>DB: SQL 查询
    DB-->>Repo: 返回结果
    Repo-->>Tool: 返回模型对象
    Tool-->>Graph: ToolResult
    
    Graph->>Service: yield done event
    Service->>User: SSE: done
```

### 分层职责

| 层级 | 目录 | 职责 |
|------|------|------|
| **API** | `app/api/v1/endpoints/` | HTTP 入口、参数校验、路由 |
| **Service** | `app/services/` | 业务编排、SSE 流处理 |
| **AI** | `app/ai/` | LangGraph 图、Agent、Tools |
| **Repository** | `app/repositories/` | 数据访问、CRUD 操作 |
| **Model** | `app/models/` | ORM 定义、表结构 |

> 详细说明请参阅 [后端架构](../开发文档/架构设计/后端架构.md)

### 多智能体架构

系统采用 **Supervisor 模式** 的多智能体架构：

```mermaid
graph TD
    START([用户输入]) --> PREPROCESS[预处理节点]
    PREPROCESS --> SUPERVISOR[Supervisor]
    
    SUPERVISOR --> |简单任务| SIMPLE[直接调用工具]
    SUPERVISOR --> |复杂分析| DATA[数据专家]
    SUPERVISOR --> |待办管理| TODO[待办专家]
    
    SIMPLE --> POSTPROCESS
    DATA --> EVALUATE{评估}
    TODO --> EVALUATE
    
    EVALUATE --> |任务完成| POSTPROCESS[后处理]
    EVALUATE --> |需要继续| SUPERVISOR
    
    POSTPROCESS --> END([返回结果])
```

> 详细说明请参阅 [多智能体工作流](../开发文档/代码解读/多智能体工作流.md)
