## 1. 目标与边界

### 1.1 目标

1. 将模型选择从硬编码转为可配置路由。
2. 支持“主对话/SQL生成/轻量任务/Embedding/Vision”分层展示。
3. 路由变更可审计、可回滚、可在不重启服务下生效。

### 1.2 非目标

1. 不替代模型提供商管理（provider/model CRUD 仍由 LLM 管理接口负责）。
2. 不在本模块内定义业务 prompt 细节。

---

## 2. 典型用户故事

1. **平台管理员**：我希望将 SQL 生成从 `qwen-plus` 切到其他模型并即时生效。
2. **平台管理员**：我希望配置“主对话默认模型”，让用户未手动选模型时统一命中指定模型。
3. **算法工程师**：我希望轻量任务（意图分类、参数提取、评估）与重任务模型分离配置。
4. **运维人员**：我希望路由配置优先读取数据库，可通过配置中心回滚。

---

## 3. 功能需求

### 3.1 路由总览

1. 提供模型路由列表接口，输出场景、调用点、当前模型、推荐模型、是否可编辑。
2. 展示层分组至少包括：
   - 主对话
   - SQL 生成/内部分析
   - 轻量任务
   - Embedding
   - Vision

### 3.2 路由更新

1. 支持更新以下路由：
   - `model_routing.default_chat`（主对话默认模型）
   - `model_routing.lightweight`
   - `model_routing.sql_generation`
   - `vision`（Vision 路由，切换 `model_type=vision` 的默认模型）
2. `model_routing.default_chat` 必须指向已启用的 `chat` 类型模型。
3. `vision` 必须指向已启用的 `vision` 类型模型。
4. 更新时必须校验模型存在且处于启用状态。
5. 更新后刷新配置缓存，无需重启。

### 3.3 运行时读取策略

1. `default_chat/lightweight/sql_generation` 优先读取 `t_system_config`。
2. `vision/embedding` 读取 `t_llm_model` 中对应 `model_type` 的默认模型。
3. 主对话链路在用户未显式传 `model_id` 时，优先读取 `model_routing.default_chat`。
4. 若配置缺失，回退到类型默认模型（chat 类型）与环境变量默认值。
5. 轻量任务与评估任务共享轻量模型配置键。

### 3.4 开发接入约束

1. 新增业务代码调用 LLM 时，必须先确定调用场景并使用 `get_scene_llm(scene=...)`。
2. 若场景不属于既有 `default_chat/lightweight/sql_generation`，必须先在场景注册表中完成配置。
3. 新增场景若需后台可配置，必须同步接入 `llm_admin_api` 的模型路由管理接口。
4. 代码仓库通过单测约束“禁止新增裸 `get_llm()` 默认分支调用”。

---

## 4. 共享能力引用（单一真理来源）

1. **模型路由键定义**：以 `app/core/config.py` 为权威来源。
2. **管理入口**：以 `llm_admin_api` 为唯一可写入口。
3. **业务消费**：问数与待办 workflow 只读路由结果，不重复定义。

---

## 5. 验收标准

### 5.1 Happy Path

1. 管理员可查看路由总览并更新可编辑项。
2. 更新后实际业务调用命中新模型。
3. Embedding 等只读项在接口层被拒绝修改；Vision 允许通过路由接口切换。

### 5.2 边界与异常

1. 非法配置键返回 400。
2. 模型不存在或未启用返回 400。
3. 配置中心读取失败时回退环境变量并记录日志。

### 5.3 稳定性

1. 路由变更不影响历史线程读取。
2. 轻量/重任务路由切换后不出现类型错配导致的运行时异常。

---

## 6. 非功能需求

1. **可观测性**：记录配置变更日志（key、old/new、操作者）。
2. **安全性**：仅管理员可更新路由。
3. **一致性**：后台展示、配置中心、运行时消费三者字段命名一致。

## 8. 当前风险与改造优先级

1. `P0`：模型测试依赖真实 API Key，导致路由相关单测可重复性不足。
2. `P1`：路由变更影响面横跨 workflow，需建立回归矩阵。
3. `P2`：模型路由文档与后台说明仍可进一步统一。
