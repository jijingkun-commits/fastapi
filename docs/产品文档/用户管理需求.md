| 角色 | 能力范围 |
|------|----------|
| **管理员** | 用户列表查看、用户创建、用户禁用/启用 |
| **普通用户** | 登出、批量删除自己的对话 |

## 2. 用户故事与验收标准

### US-USER-01: 用户列表查看

**角色**：作为管理员  
**需求**：我想查看系统中所有用户的列表  
**目的**：以便了解系统用户情况并进行管理

**验收标准**：
- AC-1: 用户列表支持分页，每页默认 20 条
- AC-2: 可按用户名、手机号搜索
- AC-3: 列表展示用户名、手机号、角色、机构、状态（启用/禁用）、创建时间
- AC-4: 仅管理员角色可访问此页面

**关联测试**：TC-USER-01

---

### US-USER-02: 用户创建

**角色**：作为管理员  
**需求**：我想创建新用户  
**目的**：以便为新员工开通系统访问权限

**验收标准**：
- AC-1: 创建时需填写用户名（必填，唯一）、密码（必填）、手机号（选填）
- AC-2: 可指定用户角色（user/analyst/admin）
- AC-3: 可指定机构代码、机构名称、部门代码、部门名称
- AC-4: 用户名重复时提示明确错误
- AC-5: 新创建的用户默认为启用状态

**关联测试**：TC-USER-02

---

### US-USER-03: 用户禁用与启用

**角色**：作为管理员  
**需求**：我想禁用或启用某个用户  
**目的**：以便控制用户的系统访问权限

**验收标准**：
- AC-1: 禁用后，该用户无法登录系统
- AC-2: 禁用后，该用户的已登录 Token 立即失效（强制踢出）
- AC-3: 启用后，该用户可正常登录
- AC-4: 管理员不能禁用自己
- AC-5: 操作有二次确认提示

**关联测试**：TC-USER-03

---

### US-USER-04: 用户登出

**角色**：作为已登录用户  
**需求**：我想主动退出登录  
**目的**：以便安全离开系统或切换账户

**验收标准**：
- AC-1: 点击登出后，当前 Token 失效
- AC-2: 页面跳转到登录页
- AC-3: 使用旧 Token 访问接口返回 401

**关联测试**：TC-USER-04

---

### US-USER-05: 对话批量删除

**角色**：作为已登录用户  
**需求**：我想批量删除多个对话  
**目的**：以便快速清理不需要的历史对话

**验收标准**：
- AC-1: 对话列表支持多选模式
- AC-2: 选中后显示已选数量和批量删除按钮
- AC-3: 批量删除前有二次确认
- AC-4: 删除后同时清理对话相关的附件资产（MinIO 文件）
- AC-5: 只能删除自己的对话

**关联测试**：TC-USER-05

## 3. 非功能需求

| 维度 | 要求 |
|------|------|
| **安全** | 用户管理页面仅管理员可访问；密码存储使用 bcrypt 加密 |
| **性能** | 用户列表查询响应 < 500ms |
| **可用性** | 操作失败需提示明确错误信息 |
| **审计** | 用户禁用/启用操作需记录日志（后续迭代） |

## 4. 数据模型扩展

### t_user 表扩展

| 字段 | 类型 | 说明 |
|------|------|------|
| is_active | BOOLEAN | 是否启用，默认 TRUE |

### t_token_blacklist 表（新增）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL | 主键 |
| token_jti | VARCHAR(64) | JWT ID，唯一索引 |
| user_id | INTEGER | 关联用户 |
| expires_at | TIMESTAMP | Token 原过期时间 |
| created_at | TIMESTAMP | 加入黑名单时间 |

## 5. API 设计概览

| 方法 | 路径 | 描述 | 权限 |
|------|------|------|------|
| GET | /api/v1/users | 用户列表（分页） | admin |
| POST | /api/v1/users | 创建用户 | admin |
| PATCH | /api/v1/users/{id}/status | 禁用/启用用户 | admin |
| POST | /api/v1/logout | 用户登出 | 已登录 |
| DELETE | /api/v1/chat/threads/batch | 批量删除对话 | 已登录 |
