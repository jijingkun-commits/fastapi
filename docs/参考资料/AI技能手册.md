# 🌌 Antigravity AI 技能手册

> **项目专属技能库**
> **更新时间**: 2026-01-22

本文档列出了项目中集成的 Agent 业务技能。这些技能通过 RAG 机制动态注入到 AI 上下文中。

---

## 🏢 办公与效率 (Business & Office)

| 技能 ID | 名称 | 用途 | 触发示例 |
| :--- | :--- | :--- | :--- |
| `todo-intent` | **待办意图识别** | 识别待办增删改查意图，提取结构化字段。 | "帮我记录明天上午10点开会" |
| `meeting-minutes` | **会议纪要专家** | 将乱序的会议记录整理为结构化纪要。 | "把这段会议记录整理一下" |
| `email-pro` | **商务邮件助手** | 撰写周报、客户回复、委婉拒绝等专业邮件。 | "帮我给这封邮件写个委婉的拒绝回复" |
| `data-insight` | **数据洞察专家** | 对数据图表进行深度业务解读和趋势分析。 | "分析一下上季度的销售数据" |
| `copywriter` | **文案润色专家** | 优化文案表达，提升可读性和吸引力。 | "帮我润色一下这段文案" |
| `translator` | **中英互译专家** | 提供高质量的中英文翻译，保留原文风格和专业术语。 | "翻译这段话" |

## 💻 开发工具 (Development Tools)

| 技能 ID | 名称 | 用途 | 触发示例 |
| :--- | :--- | :--- | :--- |
| `sql-expert` | **SQL 专家** | 分析自然语言需求，生成精准的 SQL 查询语句。 | "查找过去30天下单超过3次的用户" |
| `code-review` | **代码审查助手** | 审查代码质量，发现潜在问题，提供改进建议。 | "帮我 review 这段代码" |
| `python-debug` | **Python 调试专家** | 分析 Python 错误信息，定位问题根因，提供修复方案。 | "这个报错是什么意思" |
| `regex-wizard` | **正则表达式生成器** | 根据匹配需求生成正则表达式，并提供测试用例。 | "写个正则匹配手机号" |
| `api-doc` | **API 文档生成器** | 根据代码自动生成标准的 API 接口文档。 | "给这个接口生成文档" |
| `git-commit` | **Git 提交信息生成器** | 根据代码变更生成规范的 Git Commit Message。 | "生成 commit message" |
