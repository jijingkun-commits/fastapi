## 1. 目标

- 本包目标：将 `/admin` 改造为 8 块实时驾驶舱页面，并接入 summary + stream。
- 完成定义（DoD）：
  1. 首屏展示健康分、请求质量、稳定性、容量成本、告警、新鲜度、模块矩阵、变更流。
  2. SSE 连接断开自动降级到轮询，并有状态提示。
  3. 异常项可跳转到对应管理模块路由。

## 3. 状态与契约

- 可写字段：前端展示状态、降级交互、模块跳转交互。
- 只读字段：后端健康分算法与 SSE 契约（仅读）。
- 单写入权：前端 UI 状态枚举映射由 WS-04 唯一维护。

---

## 4. 实施步骤

1. 新建总览 API 客户端（summary/trends/stream）。
2. 实现驾驶舱 8 块组件与布局。
3. 接入 SSE 增量更新 + 轮询降级策略。
4. 增加骨架屏、数据过期、无数据提示态。
5. 添加 E2E 用例覆盖核心交互。
