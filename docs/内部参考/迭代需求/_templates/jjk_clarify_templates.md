# `/jjk-clarify` 项目主模板

## 1) 单主题问题包模板

```markdown
## 本轮澄清主题：<主题名>

A. 目标优先级（单选）
1) 先可用 2) 先稳定 3) 先性能

B. 范围边界（多选）
1) 仅后端 2) 前后端都改 3) 含工作流/编排

C. 交付约束（单选）
1) 本周交付 2) 可分阶段 3) 先出方案不开发

请按 `A?/B?/C?` 回复。
```
