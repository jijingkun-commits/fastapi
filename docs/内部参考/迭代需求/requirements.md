# 需求文档 (Requirements) - Todo Agent 简化版

**核心目标**: 简化 Agent 功能，专注于**单个待办事项**的精准处理。移除复杂的多任务/项目管理逻辑。

> **详细模块需求**请参考：
> - `docs/产品文档/待办助手需求.md`
> - `docs/产品文档/聊天系统需求.md`
> - `docs/产品文档/管理后台需求.md`
> - `docs/产品文档/问数助手需求.md`

## 1. 保留功能 (Keep)

### 1.1 基础能力
- [x] **创建 (Create)**: 识别标题、时间、优先级、分类、标签。
- [x] **查询 (Query)**: 支持多维度过滤搜索（前端 UI 列表展示）。
- [x] **更新 (Update)**: 修改任务属性。
- [x] **删除 (Delete)**: 删除任务。
- [x] **完成 (Complete)**: 标记完成。

### 1.2 智能增强 (对话层)
- [x] **意图识别**: 准确识别上述基础意图。
- [x] **多轮澄清**: 缺少关键信息（如时间）时主动追问。
- [x] **智能确认**: 关键操作（增删改）前弹出确认卡片。
- [x] **模糊指代 (Entity Resolution)**: 支持 "修改它"、"把那个任务..." 等上下文指代。
- [x] **冲突检测**: (轻量级) 提示时间冲突，但不阻断。

### 1.3 前端能力 (非对话)
- [x] **批量完成**: *仅保留前端 UI 勾选操作支持，Agent 对话不支持批量指令。*
- [x] **批量创建**: *仅保留前端 UI 导入/粘贴支持 (如有)，Agent 对话不支持。*

---

## 2. 移除功能 (Remove) - 以简化系统

### 2.1 对话层移除 (为了专注“单个任务”)
- [x] **批量操作意图**: 移除 `batch_create`, `batch_complete` 的意图识别。（2026-02-01 已完成）
- [ ] **任务拆解 (Decomposition)**: 移除自动拆解复杂任务为子任务的功能。
- [ ] **任务合并 (Merge)**: 移除合并任务的建议和逻辑。
- [ ] **项目管理 (Project Context)**: 移除多项目上下文切换逻辑。
- [ ] **任务汇总 (Summarize)**: 移除周报/日报汇总意图 (查询结果列表即可作为一种展示)。

## 3. 验收标准
1.  对话在处理单任务指令时响应更快、更稳。
2.  输入 "明天开会，后天吃饭"，系统**不再**尝试创建两个任务，而是可能只识别第一个或请求分开输入（或者作为单个任务标题）。
3.  输入复杂任务描述，**不再**触发拆解流程。
4.  不再出现 Project 相关的状态维护。
