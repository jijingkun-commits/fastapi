## 1. 作用说明

本文件仅作为“问题修复计划目录入口”，不再承载单个问题的完整诊断与实施正文。

维护规则：

1. 每个问题单独落地为 `fix_plan_<topic>_<date>.md`。
2. 本入口固定维护“编号、状态、负责人、最后更新、链接”。
3. 新增/关闭问题时，需同步更新 `docs/SUMMARY.md`。

## 3. 状态定义

1. `规划中`：已完成诊断，待排期实施。
2. `进行中`：已进入开发或联调。
3. `已完成`：修复上线并完成回归。
4. `已关闭`：问题不再处理（需记录关闭原因）。

---

## 4. 使用方式

1. 新问题先建专题问题卡，再回填本索引。
2. 状态变化时只更新本索引，不在入口文档记录过程流水。
3. 复盘时从索引跳转到专题问题卡查看完整证据链。
