## 1. LLM 提供商

项目支持多个 LLM 提供商，通过统一接口调用。

### 支持的提供商

| 提供商 | 模型示例 | API 兼容 |
|--------|----------|----------|
| OpenAI | gpt-4o, gpt-4-turbo | OpenAI |
| Qwen | qwen-max, qwen-plus | OpenAI 兼容 |
| DeepSeek | deepseek-chat | OpenAI 兼容 |

### 配置方式

**环境变量**:

```bash
MODEL_PROVIDER=qwen
QWEN_MODEL_NAME=qwen-max
QWEN_API_KEY=sk-xxx
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

**数据库配置（推荐）**:

通过 `t_llm_provider` 和 `t_llm_model` 表管理。

### 代码使用

```python
from app.ai.llm_util import get_llm, get_llm_by_model_id

# 获取默认模型
llm = get_llm()

# 获取指定模型
llm = get_llm_by_model_id("deepseek-chat")

# 启用深度思考
llm = get_llm(enable_thinking=True)
```

### 特性支持

| 特性 | OpenAI | Qwen | DeepSeek |
|------|--------|------|----------|
| 流式输出 | ✅ | ✅ | ✅ |
| 工具调用 | ✅ | ✅ | ✅ |
| 深度思考 | ❌ | ✅ | ✅ |
| 多模态 | ✅ | ✅ | ❌ |

## 2. RAGFlow 知识库

项目集成了 RAGFlow 知识库系统用于文档检索。

### 配置

```bash
RAGFLOW_BASE_URL=http://localhost:9380
RAGFLOW_API_URL=http://localhost:9380/api/v1
RAGFLOW_API_KEY=ragflow-xxx
RAGFLOW_DATASET_IDS=dataset1,dataset2
RAGFLOW_PAGE_SIZE=8
RAGFLOW_TOP_K=64
RAGFLOW_SIMILARITY_THRESHOLD=0.2
RAGFLOW_VECTOR_WEIGHT=0.6
RAGFLOW_ENABLE_CANDIDATE_DEDUP=true
RAGFLOW_ENABLE_DOC_CAP=true
RAGFLOW_MAX_CHUNKS_PER_DOC=2
RAGFLOW_ENABLE_QUERY_REWRITE=false
RAGFLOW_ENABLE_MULTI_ROUTE_RERANK=false
RAGFLOW_ENABLE_DOMAIN_ROUTING=false
RAGFLOW_ROLLOUT_STAGE=baseline
RAGFLOW_ROLLOUT_TRAFFIC_PERCENT=100
RAGFLOW_ROLLBACK_TARGET_STAGE=s4
RAGFLOW_ENABLE_ROLLBACK_SWITCH=true
```

### RAG 参数章节（P2 分阶段治理）

| 参数 | 默认值 | 说明 |
|---|---|---|
| `RAGFLOW_PAGE_SIZE` | `8` | 最终返回证据卡片条数上限（展示层） |
| `RAGFLOW_TOP_K` | `64` | 向量召回候选深度（召回层） |
| `RAGFLOW_ENABLE_CANDIDATE_DEDUP` | `true` | 同文档相同内容去重开关 |
| `RAGFLOW_ENABLE_DOC_CAP` | `true` | 单文档候选限额开关 |
| `RAGFLOW_MAX_CHUNKS_PER_DOC` | `2` | 单文档最多保留 chunk 数 |
| `RAGFLOW_ENABLE_QUERY_REWRITE` | `false` | 查询改写扩展路开关 |
| `RAGFLOW_ENABLE_MULTI_ROUTE_RERANK` | `false` | 多路融合重排开关 |
| `RAGFLOW_ENABLE_DOMAIN_ROUTING` | `false` | 领域路由与 metadata 过滤开关 |
| `RAGFLOW_ROLLOUT_STAGE` | `baseline` | 灰度档位：`baseline/g1/g2/g3` |
| `RAGFLOW_ROLLOUT_TRAFFIC_PERCENT` | `100` | 灰度流量占比，推荐 `10 -> 30 -> 100` |
| `RAGFLOW_ROLLBACK_TARGET_STAGE` | `s4` | 触发回滚时的目标稳定阶段 |
| `RAGFLOW_ENABLE_ROLLBACK_SWITCH` | `true` | 回滚开关（建议生产保持开启） |

### 检索观测日志字段（S5 灰度）

`knowledge_search` 结束后会记录统一结构化日志（`RAGFlow 检索观测`），核心字段：

- `phase`：`start` / `complete`
- `route_ids`、`route_count`、`fallback_routes`
- `selected_chunks`、`selected_document_ids`
- `tool_message_count`、`truncated_tool_message_count`（编排层）
- `rollout.stage`、`rollout.traffic_percent`、`rollout.rollback_target_stage`
- `rollout.rollback_switch_enabled`

### 使用方式

通过 `knowledge_search` 工具自动检索：

```python
# AI 自动调用，无需手动处理
# 用户输入："在知识库里搜索关于销售的文档"
# AI 调用 -> knowledge_search(query="销售")
```

### API 接口

**检索文档** (内部调用):

```python
POST {RAGFLOW_API_URL}/retrieval
Headers:
  Authorization: Bearer {RAGFLOW_API_KEY}
Body:
  {
    "dataset_ids": ["xxx"],
    "question": "查询内容",
    "page_size": 8,
    "top_k": 64,
    "similarity_threshold": 0.2,
    "vector_similarity_weight": 0.6,
    "metadata_condition": {
      "operator": "and",
      "conditions": [
        {
          "field": "domain",
          "operator": "eq",
          "value": "process"
        }
      ]
    }
  }
```

**图片代理**:

```
GET /api/v1/assets/proxy/ragflow/{image_id}
```

## 3. MinIO 对象存储

项目使用 MinIO 作为对象存储服务，存储聊天资产（图片、图表、导出文件）。

### 配置

```bash
MINIO_ENDPOINT=localhost:19000
MINIO_ACCESS_KEY=admin
MINIO_SECRET_KEY=12345678
MINIO_SECURE=false
MINIO_BUCKET_ASSETS=chat-assets
```

### Bucket 结构

| Bucket | 用途 |
|--------|------|
| `chat-assets` | 聊天资产（图表、导出） |
| `uploads` | 用户上传文件 |

### 代码使用

```python
from app.core.storage import upload_to_minio, get_presigned_url

# 上传文件
object_key = upload_to_minio(
    file_content=data,
    file_name="chart.png",
    content_type="image/png",
    bucket="chat-assets"
)

# 获取预签名 URL
url = get_presigned_url(object_key, expires=3600)
```

### 生命周期策略

资产默认 30 天后过期，在 `install/scripts/init_minio_buckets.py` 中配置。
