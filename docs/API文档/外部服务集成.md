# 外部服务集成

> 本项目集成的外部服务和第三方 API。

---

## 1. LLM 提供商

项目支持多个 LLM 提供商，通过统一接口调用。

### 支持的提供商

| 提供商 | 模型示例 | API 兼容 |
|--------|----------|----------|
| OpenAI | gpt-4o, gpt-4-turbo | OpenAI |
| Qwen | qwen-max, qwen-plus | OpenAI 兼容 |
| DeepSeek | deepseek-chat | OpenAI 兼容 |

### 配置方式

**环境变量**:

```bash
MODEL_PROVIDER=qwen
QWEN_MODEL_NAME=qwen-max
QWEN_API_KEY=sk-xxx
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

**数据库配置（推荐）**:

通过 `t_llm_provider` 和 `t_llm_model` 表管理。

### 代码使用

```python
from app.ai.llm_util import get_llm, get_llm_by_model_id

# 获取默认模型
llm = get_llm()

# 获取指定模型
llm = get_llm_by_model_id("deepseek-chat")

# 启用深度思考
llm = get_llm(enable_thinking=True)
```

### 特性支持

| 特性 | OpenAI | Qwen | DeepSeek |
|------|--------|------|----------|
| 流式输出 | ✅ | ✅ | ✅ |
| 工具调用 | ✅ | ✅ | ✅ |
| 深度思考 | ❌ | ✅ | ✅ |
| 多模态 | ✅ | ✅ | ❌ |

## 2. RAGFlow 知识库

项目集成了 RAGFlow 知识库系统用于文档检索。

### 配置

```bash
RAGFLOW_BASE_URL=http://localhost:9380
RAGFLOW_API_URL=http://localhost:9380/api/v1
RAGFLOW_API_KEY=ragflow-xxx
RAGFLOW_DATASET_IDS=dataset1,dataset2
RAGFLOW_SIMILARITY_THRESHOLD=0.2
RAGFLOW_TOP_K=5
RAGFLOW_VECTOR_WEIGHT=0.6
```

### 使用方式

通过 `knowledge_search` 工具自动检索：

```python
# AI 自动调用，无需手动处理
# 用户输入："在知识库里搜索关于销售的文档"
# AI 调用 -> knowledge_search(query="销售")
```

### API 接口

**检索文档** (内部调用):

```python
POST {RAGFLOW_API_URL}/retrieval
Headers:
  Authorization: Bearer {RAGFLOW_API_KEY}
Body:
  {
    "dataset_ids": ["xxx"],
    "question": "查询内容",
    "top_n": 5,
    "similarity_threshold": 0.2
  }
```

**图片代理**:

```
GET /api/v1/assets/proxy/ragflow/{image_id}
```

## 3. MinIO 对象存储

项目使用 MinIO 作为对象存储服务，存储聊天资产（图片、图表、导出文件）。

### 配置

```bash
MINIO_ENDPOINT=localhost:19000
MINIO_ACCESS_KEY=admin
MINIO_SECRET_KEY=12345678
MINIO_SECURE=false
MINIO_BUCKET_ASSETS=chat-assets
```

### Bucket 结构

| Bucket | 用途 |
|--------|------|
| `chat-assets` | 聊天资产（图表、导出） |
| `uploads` | 用户上传文件 |

### 代码使用

```python
from app.core.storage import upload_to_minio, get_presigned_url

# 上传文件
object_key = upload_to_minio(
    file_content=data,
    file_name="chart.png",
    content_type="image/png",
    bucket="chat-assets"
)

# 获取预签名 URL
url = get_presigned_url(object_key, expires=3600)
```

### 生命周期策略

资产默认 30 天后过期，在 `install/scripts/init_minio_buckets.py` 中配置。
