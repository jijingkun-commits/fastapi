# API 概述

本项目提供 RESTful API 接口，所有接口均以 `/api/v1` 为前缀。

## 基础信息

- **Base URL**: `http://localhost:8000/api/v1`
- **认证方式**: JWT Bearer Token
- **请求格式**: JSON
- **响应格式**: JSON

## 认证

除登录接口外，所有接口需要在 Header 中携带 Token：

```
Authorization: Bearer <token>
```

## 通用响应格式

### 成功响应

```json
{
  "data": { ... },
  "message": "操作成功"
}
```

### 错误响应

```json
{
  "detail": "错误信息"
}
```

### HTTP 状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 201 | 创建成功 |
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 422 | 参数验证错误 |
| 500 | 服务器错误 |

## SSE 流式接口

聊天接口使用 Server-Sent Events (SSE) 返回流式响应：

```
POST /api/v1/chat/stream
Content-Type: application/json

{"prompt": "你好", "thread_id": "xxx"}
```

响应为事件流：

```
event: token
data: {"content": "你好"}

event: done
data: {"thread_id": "xxx"}
```

详细事件类型请参考 [SSE 流式响应](../功能详解/SSE流式响应.md)。
