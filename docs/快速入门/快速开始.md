# 快速开始

本指南帮助你在 5 分钟内运行项目并体验核心功能。

## 前置条件

- Docker 和 Docker Compose 已安装
- Python 3.11+ 已安装
- Node.js 18+ 和 pnpm 已安装

---

## 第一步：启动服务

```bash
# 克隆项目
git clone <repo-url>
cd fastapi

# 启动基础设施（PostgreSQL + MinIO）
docker compose up -d

# 等待服务就绪
docker compose ps
```

---

## 第二步：配置环境

```bash
# 复制配置文件
cp .env.example .env.dev

# 编辑配置（至少需要配置 LLM API Key）
# 打开 .env.dev，设置：
# MODEL_API_KEY=你的API密钥
```

---

## 第三步：启动后端

```bash
# 安装依赖
pip install -e ".[dev]"

# 启动服务
uvicorn app.main:app --reload --port 8000
```

验证：访问 `http://localhost:8000/docs` 查看 API 文档。

---

## 第四步：启动前端

```bash
# 新开一个终端
cd web
pnpm install
pnpm dev
```

访问：`http://localhost:3000`

---

## 第五步：体验功能

### 登录系统

首次运行时，在 `.env.dev` 中设置 `INIT_DB_ON_STARTUP=true`，重启后端会自动创建管理员账户：

- 用户名：`admin`
- 密码：`secret`

### 对话测试

1. 登录后进入聊天界面
2. 输入：`你好，请介绍一下你的功能`
3. 观察流式响应输出

### 待办助手

1. 输入：`帮我添加一个待办：明天下午3点开会`
2. 观察 AI 如何理解并确认任务
3. 查看待办列表确认添加成功
