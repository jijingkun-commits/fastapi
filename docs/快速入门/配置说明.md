# 配置说明

本文档详细介绍项目的所有配置项，包括环境变量和数据库动态配置。

## 配置文件

| 文件 | 用途 |
|------|------|
| `.env.dev` | 开发环境配置 |
| `.env.prod` | 生产环境配置 |
| `.env.example` | 配置模板 |

环境由 `ENV` 变量决定，默认为 `dev`。

---

## 数据库配置

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `DATABASE_URL` | `postgresql+psycopg://postgres:postgres@localhost:5432/chat_db` | 数据库连接串 |
| `DB_POOL_SIZE` | `5` | 连接池大小 |
| `DB_MAX_OVERFLOW` | `10` | 最大溢出连接数 |
| `DB_POOL_RECYCLE` | `1800` | 连接回收时间（秒） |
| `DB_POOL_TIMEOUT` | `30` | 连接超时时间（秒） |
| `DB_ECHO` | `true` (dev) / `false` (prod) | 是否打印 SQL |

### LangGraph Checkpointer

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `PG_CHECKPOINTER_URI` | `postgres://postgres:postgres@localhost:5432/checkpoints` | Checkpoint 存储连接串 |

## 数据库动态配置

以下配置存储在数据库中，可在运行时通过 API 修改，无需重启服务。

### LLM 模型配置

表 `t_llm_provider` 和 `t_llm_model` 管理模型配置。

**服务**: `LLMConfigService`

```python
# 获取模型配置
config = LLMConfigService.get_model_config("qwen-max")

# 获取默认模型
default = LLMConfigService.get_default_model_code()

# 列出可用模型
models = LLMConfigService.list_available_models()
```

### 系统配置

表 `t_system_config` 管理系统级配置。

**服务**: `SystemConfigService`

```python
# 获取配置（支持类型化获取）
value = SystemConfigService.get("key", "default")
number = SystemConfigService.get_int("max_retries")
flag = SystemConfigService.get_bool("feature_enabled")
```
